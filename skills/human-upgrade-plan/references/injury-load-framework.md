# 伤病负荷管理手册（不是诊断库）

核验日期：2026-10-10。  
本文件管：**红旗转介、减冲击、换动作、回归节奏**。不命名疾病、不开药、不设「疼低于几分就能跑」。

阶段门仍走 [伤后回归树](gold-weeks-and-return.md)。动作替换走 [力量第9节](strength-training-modes.md)。证据：[iwr-core](evidence/iwr-core.md)。

---

## 铁律

1. 红旗 → 停诱发课并就医。  
2. 功能（跛、肿、次日更差）优先于手表恢复分。  
3. 防伤力量值得每周做一小份，**不保证零伤**（IWR01）。有监督/能完成比复杂计划重要。  
4. **没有普适「每周加 10%」公式**（IWR02/IWR03）。一次只改一个负荷变量。  
5. 部位表是负荷假设，不是确诊。

---

## 红旗（停，不排诱发）

胸痛/晕厥/明显气短；夜间局灶骨痛；单侧小腿肿热；放射麻木或进行性无力；跟腱枪响/断裂感；膝锁死不稳；茶色尿、极度无力、少尿（超野后，见 RP19）。

## 部位负荷菜单（像 X 就这样减，不说「你得了 Y」）

| 用户描述 | 先减什么 | 仍可做什么 | 转介 |
|---|---|---|---|
| 髌周、上下楼痛、下蹲底痛 | 深跳、下山速度、深杠铃蹲 | 平路轻松、髋推/腿举短行程 | 跛或肿加重 |
| 外侧膝、下坡/弯道加重 | 下坡速度、弯道质量、突然加量 | 平路轻松；cadence 可作试验不加保证 | 同上 |
| 跟腱晨起第一脚、快提踵痛 | 跳、冲刺、上坡冲、快提踵 | 平路轻松；慢双腿提踵渐进 | 晨僵加重或枪响感 |
| 足底第一步痛 | 赤足/硬地速度、跳 | 平路轻松；可忍的小腿负荷 | 夜间骨痛样 |
| 胫骨内侧酸、越跑越锐 | 冲击、坡、速度 | 走或骑；量先砍 | 点状夜间痛 → 按骨应力怀疑转介 |
| 后腿高速跑后内侧痛 | 大剂量冲刺/北欧 | 轻松跑；慢铰链若无痛 | 锐痛或无力 |
| 下背 hinging/久坐后 | 重 RDL、反复屈体力竭 | 髋推、死虫、轻松平路 | 放射下肢 |

回归节奏：S0–S6，连续 2–3 次成功且次日不更差才升级。失败退一阶段。

## 骨应力怀疑（本 skill 不诊断，只停跑+转介）

夜间局灶骨痛、单腿跳/跑步局部锐痛进行性加重、训练量刚猛增 + 女选手/低能量可用 → **停冲击跑跳，就医影像评估**。不要用 S2 走跑「试试看」。国际 Delphi（IWR13）：多因素管理、个体回归；高危部位回归更慢（IWR14）。能量不足走营养包 IOC REDs，补铁仍需医嘱。

既往伤、女交叉跑者、RED-S 风险是学校/大学组里较强的相关因素（IWR12）——**不可改的风险用减冲击补，可改的是睡眠、加量速度、能量**。

伞状综述（IWR11）：伤是多因素，综述质量低；禁止凭一条生物力学或一双鞋下诊断。

## 按运动员类型

| 类型 | 默认 |
|---|---|
| 大众 | 每周固定 15–25 min 髋/单腿/小腿/抗旋转即可；不新开复杂防伤课 |
| 进阶 | 同上，质量周不叠新冲击（新鞋+下山+间歇） |
| 学生体测 | 痛了先保动作干净的短加速，不堆乳酸 |
| 上班族 | 久坐先打断；痛时优先睡眠与减冲击，不加 HIIT 补偿 |
| 伤后 | 只走回归树，比赛日期要重算备赛周数 |
