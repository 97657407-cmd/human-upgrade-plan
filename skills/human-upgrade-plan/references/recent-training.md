# 近期记录与更新

本文件是读取规则，不含用户当前状态。

- **排今天的课之前先看最近一次实际完成**（高驰则拉上次运动+睡眠）；排周计划再看 7–28 天窗口与中断。这只是工作窗口，不是医学或进阶频率。
- **数据优先级**：用户明确授权且 COROS MCP 可用时，先拉取该窗口活动与睡眠/恢复，再请用户补主观与症状；MCP 失败或未授权则退回手动日志。其他品牌手表以用户提供的摘要为准。详见 [设备数据](device-data.md)。
- 为每次课标记：计划中、已完成、部分完成、取消、未确认。未反馈不推算里程；“打算补课”不记为完成。手表有记录但用户说没练完时，以双方差异记“待确认”。
- 区分外部负荷（时间、距离、速度、坡度、力量组次）和内部反应（sRPE、呼吸、疲劳、症状）。sRPE采用0–10分；记录何时评分，保持本人前后一致。
- 同时读取睡眠、进食、工作坐站/夜班、旅行、疾病和训练意愿；职业压力与运动负荷分栏，不无依据合成总分。
- 数据单次异常先检查设备、地形、天气、配速波动和主观感受。短间歇心率滞后，腕式设备不是诊断或气体代谢测试。
- 更新时保留旧记录和变更原因，当前阶段注明“依据截至何日的数据”。新信息不足时当前阶段为待评估，不能长期继承旧阶段。

记录模板见 [training-log-template](../assets/training-log-template.md)。
