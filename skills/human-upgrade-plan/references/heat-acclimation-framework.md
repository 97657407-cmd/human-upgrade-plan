# 热习服 × 赛前降温（去热的比赛）

核验日期：2026-10-22。证据：[heat-acclimation-core](evidence/heat-acclimation-core.md) HA01–HA05。  
配速三档仍走 [赛日策略](race-day-strategy.md)。喝水走 [补水与咖啡因](hydrate-caffeine-framework.md)。穿搭走跑步穿搭。  
**不是医疗。** 高热、意识乱、不认人、不停干呕 → 急诊。发烧、未控高血压不做热习服。

赛前窗口问「要不要桑拿」「提前几天去比赛城」「赛晨喝冰」时加载。热天比赛的赛事安排必须写：习服做了没、今天用哪档、赛晨降温是否已彩排。

---

## 0. 先问清

| 块 | 要问 |
|---|---|
| 赛事 | 起跑气温/湿度、是否暴晒、完赛目标 |
| 窗口 | 离比赛还有几天；减量是否已开始 |
| 做过没 | 最近 2 周有没有在热里连续练 |
| 身体 | 发烧史、中暑史、肠胃能否喝冰 |

---

## 1. 习服 vs 降温（不要混）

| | 干什么 | 什么时候 |
|---|---|---|
| 热习服 | 让以后在热里心率和核心温更好受（HA01–HA03） | 赛前大约 1–2 周反复热暴露下运动 |
| 再诱导 | 离开热之后把掉的适应捡回来（HA04） | 赛前大约 4–5 天短热课 |
| 赛晨降温 | 临时降低出发核心温（HA05） | 仅已彩排；**不能**替代习服 |

减量周禁止新上「桑拿 + 冰浆 + 质量」暴击。

---

## 2. 按剩余天数抄（大众）

| 离热比赛 | 做什么 | 不要做什么 |
|---|---|---|
| ≥10–14 天 | 大约 5–10 次热里运动（轻松或原质量改热环境），每次大约 45–90 min 能完成的；室内跑台更热一档可当工具 | 每天 HIIT；发烧硬上 |
| 6–9 天 | 能完整则缩短版习服，承认更浅 | 把周跑量翻倍 |
| 减量已开始，只剩 4–5 天 | 若以前习服过：短再诱导（热里轻松 30–50 min × 3–5 天）（HA04） | 新上桑拿力竭 |
| ＜4 天或从未热练 | **不习服**。只降配速档 + 荫凉热身 + 口渴喝 | 赛晨第一次冰浆 |
| 赛晨 | 已彩排的浇水/冰饮/背心可选 | 未试过的 7.5 g/kg 冰浆（HA05 实验室） |

出汗会变多：热习服后更要口渴喝，仍禁止体重涨。

---

## 3. 教案格

```text
**热**
窗口：还有 N 天 · 习服：未做 / 进行中 / 已完成+再诱导
本周热暴露：哪几天、多长、室内外
赛日档：因热改保守/中位（删激进若 >20–25°C）
赛晨降温：不用 / 已彩排的浇水或冰饮（非实验室剂量）
取消：头晕意识乱停；体重涨了停灌
```

钉卡：要不要习服用 HA01；减量周时间用 HA04；赛晨冰用 HA05 边界。不要一次钉 5 张。
