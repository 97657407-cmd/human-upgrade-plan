# 硬件配件：胸带 / 臂带 / 跑步豆

核验日期：2026-10-11。证据：[hardware-kit-core](evidence/hardware-kit-core.md) + 可穿戴包 C40–C45。  
没有配件也能排课（时间 + RPE + 能说话）。有配件则**每堂写出佩戴**，按课型和气温改用法。数字冲突时听功能和 RPE，不听手表区。

## 建档必问（和手表同一块）

> 心率：胸带 / 上臂光学臂带 / 只有腕表光学 / 都没有？  
> 跑步豆（Stryd、高驰/佳明脚豆等）：有 / 没有？

记三件事：内负荷用什么（胸带 / 臂带 / 腕表 / 无）、外负荷用什么（豆 / 只有配速）、手表品牌。没有不要推销购买。已有则质量课优先提醒戴上。

## 每堂强制：出发前提醒

课表头加 `佩戴：……`。只写用户**已经有的**。

| 用户有 | 轻松跑 | 质量课 / 间歇 | 力量 |
|---|---|---|---|
| 胸带 | 可选；电极打湿 | **必须戴**；出发前电极用水打湿 | 可不戴 |
| 臂带 | 可贴紧上臂 | 可戴，但间歇别死盯跳点；有胸带则胸带优先 | 可贴 |
| 只有腕表 | 看趋势即可 | **不要用腕式心率调间歇**；用 RPE / 能说话 / 配速时间 | — |
| 跑步豆 | 可选趋势 | 建议戴；看同设备趋势，不设绝对瓦区 | 不需要 |
| 都没有 | 时间 + RPE | 同左 | 同左 |

出发前口头（有什么说什么）：

> 出门：胸带打湿电极再扣上。臂带贴紧上臂、别压在肘上。豆扣在鞋。腕表松紧一指。冷天电极尤其要湿。

## 气温 × 配件（有什么给什么）

预报气温。光学心率在 10–36°C 实验室步行里气候主效应不明显（HW03），**间歇误差主要来自动作和心率突变，不是「10°C 光学一定坏」。** 干冷主要打的是胸带接触和电池。

| 体感 | 胸带 | 臂带 / 腕表光学 | 跑步豆 |
|---|---|---|---|
| **≤8°C 或很干** | 电极打湿；贴身层里面，别隔厚衣空擦。干皮接触差是导电问题 | 臂带优于腕表（前臂晃动更小）。间歇仍优先胸带。袖口别把臂带顶松 | 豆照戴（外负荷不靠皮肤血流）。备用电放贴身层。功率不当阈值金标准 |
| **8–18°C** | 打湿即可 | 轻松跑光学够用；质量课仍胸带优先 | 照戴 |
| **>18°C 或很湿** | 汗多接触通常更好；防磨胸下 | 防汗滑；热天心率会漂，配速/RPE 仍主锚 | 热+坡：瓦数解释要降级（C44） |
| **室内跑台** | 同课型 | 同课型 | 豆可用；勿把跑台瓦数当室外区 |

胸带戴在贴身排汗层**里面**，不要戴在抓绒外面（信号和摩擦都差）。这是接触物理，与穿搭手册一起写。

---

## 课表怎么用数据（先进用法，不是玩数字）

1. **内负荷**：质量课用胸带心率；轻松跑腕表即可（HW01、HW02）。  
2. **外负荷**：豆看趋势、坡度、风；不跨品牌比瓦，不把厂商 CP 当乳酸阈（C41、C43）。  
3. **冲突**：跛、喘、RPE 和心率打架 → 听功能和 RPE。冷天腕式偏高/乱跳时，不要因此加间歇。  
4. 没有胸带的间歇课：写时间和 RPE，不写「到 170 再停」。
