# 临界速度 / 场测定强度（CS · D′ · Vpeak）

核验日期：2026-10-28。证据：[critical-speed-core](evidence/critical-speed-core.md) CV01–CV08。  
交叉：[间歇组间休息](interval-rest-framework.md) · [双阈值](double-threshold-framework.md) · [备赛](race-prep-framework.md) · [设备数据](device-data.md) · wearables 主题包。

用户问「我该跑多快、区间怎么定、临界速度/临界功率靠不靠谱、要不要做 3 分钟全力」时加载。  
**不替代实验室 VO₂max / 乳酸。** 无场测时仍用 RPE + 能说话轻松跑，不编造配速表。

---

## 0. 硬规则

1. **先定体系，再定课。** 跑道 CS、或手表/足部功率 CP，**二选一用到底**；不要同一周又抄 CS 又抄 Stryd CP 百分比（CV07）。  
2. **灰区真实存在。** CS 附近约 ±5% 可能落在 heavy 或 severe；质量课宁可略保守，也不在灰区「赌稳态」（CV02）。  
3. **D′ / W′ 别当处方主力。** CS/CP 估计相对稳；D′ 方法间一致性差（CV03）。大众间歇先控「能完成且次日能走」。  
4. **CS ≠ MLSS 同义词。** 文献上两者常差一截；不要用一次乳酸稳态否定整个 CS，也不要把 CS 配速当「能无限跑」的轻松配（CV04）。  
5. **无近期最大努力数据 → 不开 CS 处方。** 用能说话轻松 + 金样质量形状；需要锚点再约场测周。

---

## 1. 今天怎么用（决策树）

| 情况 | 做 |
|---|---|
| 有 3 次不同时长最大努力（约 3 / 7 / 12 min）或可靠 3MT | 估 CS；阈下连续 / 阈值感间歇略低于 CS；摄氧间歇略高于 CS（CV01、CV05） |
| 只有日常训练最好段（HAB） | 可估 CS，与正式 TT 常接近；D′ 仍谨慎（CV03） |
| 只有 Vpeak（场地峰值速度）+ Tlim | 也可开课；爱好者 5 周对照里 CS 与 Vpeak 处方都有效（CV06） |
| 只有手表「配速区 / 预测全马」 | **不当 CS**；轻松跑靠说话测试 |
| 伤后 / 回归 / 发烧空窗 | 先闸门与回归树；不拿旧 CS 开间歇 |

---

## 2. 场测怎么排（爱好者可抄骨架）

**优先：三次计时（平坦跑道或熟路）**  
间隔 ≥48 h，或分两周；各一次约 **3 min、7 min、12 min** 最大可持续努力（非整场比赛战术）。用距离–时间估 CS（教练或可靠 App；禁止手算瞎拟合还当精确到秒）。  
测周：**取消**另一堂狠间歇；测日热身完整；热/霾/伤标取消。

**备选：3 分钟全力（3MT）**  
CS/CP 重测信度较好；仍建议平坦、熟悉路线；D′ 波动大（CV03）。

**测完怎么写课（原则，不抄精英 %）**  
- 轻松 / 大部分周跑：远低于 CS，能说话。  
- 阈值感 / 稳态长段：略低于 CS，留出灰区缓冲。  
- VO₂ / 长间歇：略高于 CS，组间按 [间歇控时](interval-rest-framework.md)，趟数以不散架为准。  
- 短冲 / 速度：不走 CS 百分比，走短跑手册。

钉卡：CV01–CV06；一次排课 1–2 张。

## 3. 教案里怎么写

质量课必写。无场测时的句子见 [决策流](decision-flow.md) 树 B，不要留空。

```text
**强度锚点**
体系：临界速度 CS（场测 YYYY-MM-DD）/ Vpeak / 尚未场测→RPE
今天：阈感略低于 CS · 或摄氧略高于 CS · 或轻松远低于 CS · 或无测：舒适偏难短句还能说
禁：灰区硬扛 · 用旧 PB/手表区冒充 CS · 同周混用 CP% 与 CS% · 回归周用旧锚点
```

---

## 4. 无锚点默认口径（排课直接抄）

没有近 8 周最大努力时，用这张，不发明 min/km。

| 课的目的 | 写进基本部分的强度句 |
|---|---|
| 轻松、长课 | 能整句说话；不能说短句就走 |
| 阈感、节奏、金样 * 长段 | 舒适偏难，工作段还能说短句；组间慢跑恢复到能开口 |
| 摄氧、4×4、长间歇 | 工作段明显喘；组间必须恢复到能开口再开始下一趟；散了就停 |
| 短加速、体测 | 不按临界速度百分比；最后两趟动作仍干净，走回 |

场测周本身是主刺激：只留测试日 + 轻松，不另排狠间歇。测完下一周才允许把「略低 / 略高 CS」写进质量课。
