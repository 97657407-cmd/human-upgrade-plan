# 大师组 / 年龄增长跑步（约 40+）

核验日期：2026-10-28。证据：[masters-run-core](evidence/masters-run-core.md) MR01–MR06。  
交叉：[力量模式](strength-training-modes.md) · [伤病负荷](injury-load-framework.md) · [HRV 改课](hrv-session-framework.md) · [女选手周剂量](female-week-framework.md)。

用户明确年龄偏大、问「是不是该少跑、VO₂ 掉正常吗、还要不要间歇」时加载。  
**不是医疗评估。** 有心血管红旗先停质量就医。

---

## 0. 硬规则

1. **掉得快的往往是停训，不只是生日。** 大师精英纵向：训练量掉多少，和 VO₂max 掉多少强相关；维持量者每十年掉得慢得多（MR01）。  
2. **主刺激仍 ≤1 / 周**（与大脑一致）；恢复日真恢复，不要用「年龄大更要堆 HIIT」补偿。  
3. **力量不减反更重要。** 跑量可略保守，下肢维持/单腿/小腿不要先砍（MR03）。  
4. **旧 PB 不是现能力。** 锚点用近 4–8 周完成质量或场测 CS，不引用五年前全马。  
5. **女大师仍走女选手闸门**（铁、能量可用性），不另造「更年期公式课表」。

---

## 1. 今天怎么改课

| 信号 | 做 |
|---|---|
| 量掉很多、很久没质量 | 先重建轻松跑频率；质量从短段少趟起（MR01、MR02） |
| 仍能维持周跑与睡眠 | 可保留 1 次质量；形状用金样，不抄精英双阈值 |
| 腱/关节晨僵、质量后 48 h 仍沉 | 砍冲击或改骑/椭圆；力量改等长/低冲击菜单 |
| 只想「抗衰老」 | 优先可重复轻松 + 力量；间歇可选不强求 |

```text
**大师组口径**
维持可完成的周跑与力量优先于追旧配速
本周主刺激：0–1 次；锚点用近况不是旧 PB
```
