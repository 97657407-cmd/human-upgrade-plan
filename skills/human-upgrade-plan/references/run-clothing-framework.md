# 跑步穿搭（按地点气温，每堂必写）

核验日期：2026-10-11。证据：[clothing-core](evidence/clothing-core.md)。热身时长仍走 [热身手册](warmup-recovery-framework.md)。

**不是诊断，也不能保证不感冒。** 感冒是病毒，冷空气本身不会「制造病毒」。能改的是：少把气道吹透、少穿着湿衣服吹风站着、质量课后立刻换干衣（CL03–CL07）。

写室外课之前：已查该点气温、湿度、风、降水。课表头再加一行 **今日穿搭**。检索失败则给冷/热两套穿法，不假装已知。

---

## 原则（先于表格）

1. **按跑步穿，不按出门站着穿。** 跑起来产热，用休息时那套会出大汗；湿了再停，隔热会塌（CL01–CL03）。出门可以多一件，**开跑 5 分钟内脱掉或拉链开到底**。
2. **质量课比轻松跑少一层。** 强度越高，维持体温需要的衣服越少（CL02）。间歇中间、热身前后、练后，把那一层穿回来。
3. **三层：贴身排汗 → 中间保暖（可选）→ 外防风/防雨。** 贴身不要纯棉。外层有风或下雨才套上跑；无风无雨，外层留给热身/练后（CL01）。
4. **风和湿按更冷一档。** 跑步+风会把衣服里的空气层抽走（CL04）。下雨、出汗湿透 = 隔热下降。
5. **气道：干冷、大风、张嘴喘气时戴围脖或面罩，从鼻子呼吸能走就走。** 这是 EIB/局部黏膜降温，不是迷信（CL05、冬季 EIB 卡）。
6. **换季：比上周同日骤降 ≥8°C，整表再冷一档。** 秋天第一堂质量课最容易：白天 18°C 晚上 8°C，按晚上那一档 + 可脱马甲。

人手一件「场边干外套 + 干 T 恤」比再买一件贵跑衣重要。

---

## 体感气温 → 穿什么

体感 = 预报气温。**有明显风或小雨：整表降一档。** 室内跑台按室温，再按热身手册「更热一档」少穿衣服。

| 体感 | 轻松跑（能说话） | 质量课 / 间歇（会更热） | 热身前 · 组间 · 练后 |
|---|---|---|---|
| **≤0°C** | 速干长袖 + 抓绒或薄棉服 + 防风壳；长裤；手套、帽子、围脖 | 可少一件中层，拉链开；围脖保留。不要为了「练爽」短袖 | 壳穿上；立刻换干衣。极寒质量可改室内 |
| **0–8°C** | 速干长袖 + 薄抓绒或马甲；长裤或加绒裤；手套可选；围脖防风 | 长袖 + 可脱马甲；跑热了马甲塞腰，不要湿着吹 | 外套放场边；停下来先穿再聊天 |
| **8–15°C（换季高发）** | 长袖或短袖+薄外套开跑再脱；长裤或七分 | **短袖 + 带到场边的外套**；宁可开跑凉 2 分钟，不要汗透 | 热完穿外套等到第一趟（IWR30）；练后 3 分钟内换干衣 |
| **15–22°C** | 短袖短裤；女选手可加薄防走光/防晒 | 同左；湿湿热再少 | 热身缩短；练后仍不要吹风站着 |
| **>22°C 或很湿** | 最少；帽檐防晒；浅色 | 更少；热环境降配速见赛日手册 | 阴凉；中暑红旗停 |

宿舍/操场没有专业层：  
贴身 = 速干或旧合成纤维；中间 = 抓绒/卫衣（**开跑脱掉**）；外 = 能挡风的薄外套。纯棉贴身出汗后贴在身上散热最快，冷天不要当第一层。

---

## 换季和质量课（最容易「跑完就烧」的窗口）

不是跑完立刻病毒发作。常见链是：**穿成冬天出门 → 间歇大汗 → 湿衣吹风站着拉伸/等同学 → 气道和皮肤一起降温**（CL03+CL05+CL07）。

| 场景 | 怎么穿 |
|---|---|
| 秋天第一场晚上间歇，白天还热 | 按**晚上气温**；多带一件，开跑脱掉 |
| 冬天质量课 | 跑时少一层；**每一组休息把外套穿上**；不要组间短袖吹风 |
| 冬春交替、忽高忽低 | 以当天预报为准，不沿用上周搭配 |
| 雨、雪、操场积水 | 外层防风防雨；鞋袜湿了练后马上换；低强度湿冷优先改室内 |
| 室内热、外面冷（馆里力量→室外跑） | 出馆先加外套走 2–3 min，再脱到跑步套装 |

练后优先级：换干衣 → 吃饭 → 再拉伸。湿着吹 15 分钟拉伸，不如回家再拉（整理本就不是恢复神课，IWR27）。

## 课表怎么写（强制）

室外课表头：

`地点 · 室内外 · 气温 · 湿度 · 风/雨 · PM2.5 · 穿搭：……`

穿搭写成用户听得懂的一件件，例如：

> 今晚体感 9°C、有风：按 8–15°C 再冷一档。轻松跑：长袖+马甲+长裤。今晚是间歇：短袖长袖随你，**马甲/外套放跑道边，组间穿上**；围脖挡风。结束 3 分钟内换干 T 恤和外衣，不要湿着在操场聊。

下次可问：跑起来是闷汗还是一直冷？闷汗 → 下次跑步少一层、场边多留一层。一直冷 → 加帽子手套，不要加纯棉。
