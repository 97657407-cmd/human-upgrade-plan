# 跑步穿搭（IREQ / ACSM 热平衡落地）

核验日期：2026-10-11。证据：[clothing-core](evidence/clothing-core.md)。热身时长走 [热身手册](warmup-recovery-framework.md)。

写室外课必须按该点气温、风、降水给出穿搭。  
**气温分档表是教练合成**（把 ACSM Figure 2：clo × 气温 × 代谢率，以及 ISO 11079 IREQ 落到中文课表），**不是**某篇 RCT 规定「8–15°C 必须短袖」。

不能保证不感冒。病毒要接触。衣服改的是产热–散热匹配（CL01–CL04、CL09、CL11）。

---

## 理论（排课先用这五句）

1. **热平衡**：产热（代谢，随强度变）要盖过对流/辐射/蒸发散热。强度一变，所需隔热（IREQ）就变（CL02）。
2. **同一气温，质量课 IREQ 低于轻松跑，轻松跑低于站着。** 所以：跑时少一层；组间、热身前后、练后把那一层穿回来（CL01–CL02）。
3. **湿 + 风 + 低强度才会掏核心。** ACSM：5°C、全湿、5 m/s 风，>60% VO2max 核心往往还能撑；<30% VO2max 核心可以掉（CL03）。间歇主段可以湿着跑；**组间走和练后聊天不行。**
4. **不要用「open window」解释换衣服。** 现行运动免疫把赛后淋巴细胞下降看成再分布，不是免疫关机（CL07）。换衣服理由是热物理 + 练后体温调节紊乱（CL09）+ 力竭后效应器疲劳（CL11）。
5. **ISO 11079：跑段和休息段分别算所需隔热。** 间歇不是穿一个平均层数跑完全堂。

1 clo ≈ 让人在约 21°C 安静坐着舒服的隔热。跑起来代谢常到数 MET，所需 clo 远低于西装。有风时有效 clo 再降（CL04）。

---

## 原则

1. 按跑步穿，不按出门站着穿。出门可多一件，开跑数分钟内脱掉或拉链开到底。
2. 三层：贴身排汗（不要纯棉）→ 中间留空气（抓绒/马甲，可脱）→ 外层挡风挡雨。无雨无大风，外层留给休息（CL01）。
3. 有明显风或降水：整表按更冷处理（CL04、CL10）。
4. 干冷、张嘴喘气：围脖/面罩——服务 EIB 和吸入空气加温加湿（CL05–CL06），不是抗病毒保证。
5. 换季：按**开跑时段**预报，不按中午。比上周同日骤降或下雨，按更冷 + 带干外套（CL10）。

人手一件场边干外套 + 干贴身，比再买一件贵跑衣重要。

---

## 气温 → 穿什么（教练落地，个体用反馈微调）

预报气温。室内跑台按室温，再按热身手册「更热」少穿。  
轻松跑 ≈ 能说话；质量课 ≈ 明显高于轻松的代谢。

| 气温 | 轻松跑 | 质量课（跑时） | 热身 / 组间 / 练后 |
|---|---|---|---|
| **≤0°C** | 排汗长袖 + 中层 + 防风壳；长裤；手套帽围脖 | 可少一件中层、拉链通风；围脖保留 | 壳穿上；立刻换干衣。极寒质量可改室内 |
| **0–8°C** | 长袖 + 薄中层或马甲；长裤 | 长袖 + 可脱马甲 | 停下来先穿外套 |
| **8–15°C** | 长袖，或短袖+开跑再脱的薄外套 | 比轻松少一层；外套必须在场边 | 热完穿到第一枪（CL08）；练后立刻干衣 |
| **15–22°C** | 短袖短裤 | 同左或再少 | 热身缩短；仍不要湿着吹风 |
| **>22°C 或很湿** | 最少；防晒 | 更少；配速走赛日热环境 | 阴凉；中暑红旗停 |

宿舍没有专业层：贴身用速干或旧化纤；卫衣当中层，**开跑脱掉**；能挡风的薄外套当场边层。

下次用主观热感校准：跑起来闷汗 → 下次跑步少一层、场边多留一层。一直冷 → 加帽手套，不要加纯棉贴身。

## 换季和质量课（ACSM：没准备的雨天最容易低体温）

| 场景 | 决策 |
|---|---|
| 秋夜间歇、白天还热 | 按晚上气温；多带一件开跑脱 |
| 冬天间歇 | 主段少层；**每一组休息穿外套**（代谢掉到 <30% 区） |
| 忽冷忽热 | 当天预报，不沿用上周 |
| 雨、积水 | 外层防风防雨；湿袜练后马上换；低强度湿冷优先室内 |
| 馆内力量 → 室外跑 | 出馆先加外套走 2–3 min，再减到跑步套装 |

练后顺序：干衣 + 挡风 → 吃饭 → 再拉伸。湿着吹风拉伸，等于用湿衣做蒸发降温（CL09），主动整理本就不是恢复处方（IWR27）。

---

## 课表头（强制）

`地点 · 室内外 · 气温 · 湿度 · 风/雨 · PM2.5 · 穿搭（跑时 / 组间·练后）`

例：

> 今晚 9°C、有风。理论：质量课跑时 IREQ 低于站着，组间湿+风会掏体温。跑时：长袖、马甲可脱。**外套放跑道边，组间穿上**；围脖挡干冷。结束立刻换干 T 恤和外衣。
