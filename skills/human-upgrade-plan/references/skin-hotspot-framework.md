# 开课闸门：磨脚、水泡、血泡、裆大腿擦伤（长距离 / 越野）

核验日期：2026-10-12。证据：[skin-hotspot-core](evidence/skin-hotspot-core.md) SH01–SH06。  
**不是外科、不开药、不保证不感染。** 红肿向近端走、发烧、脓、血糖异常伤口 → 就医，不在聊天里清创。

长距离和越野最常见的「小伤」是皮肤摩擦，不是肌肉拉伤。越野医生站大量接诊是脚（SH01）。今天改不改课，看能不能正常着地、有没有破皮感染征。

## 1. 越野 / 长课怎么防（赛前彩排，不靠赛晨新发明）

摩擦 ≈ 潮湿 × 反复剪切（SH03）。防的是**湿和搓**，不是更贵的鞋神话。

1. **已知会起泡的那一小块**出发前贴 3M 纸胶带（医用纸胶），焦贴不要整只脚裹满。多日超马 RCT：定点贴比不贴少约四成水泡（SH02）。整脚乱贴过一次阴性试验（SH01）。  
2. 袜子：合脚、缝线少；湿了就换。越野援助站换袜是常规，不是矫情。  
3. 鞋：脚趾前留空间，尤其长下坡（黑趾甲常见于鞋头顶）。新鞋不穿去长课。沙地/碎石加鞋套减少灌沙。  
4. 趾甲平剪、略短于趾端。  
5. 润滑：大腿内侧、后跟、肩包带。粉和润滑不要在同一层乱叠成泥。  
6. 出发前不把脚泡到发白。热天脚更湿，更早处理热点。

精英越野常见做法（教练观察，不是处方）：援助站换袜、已知热点预先贴、下坡略减步长。禁止抄谁涂了什么处方药。

## 2. 已经起泡 / 出血了怎么办（小细节）

**完整小泡：** 不要挑。纸胶或水胶体敷料盖上，减摩擦。能走路再考虑轻松跑。

**又大又紧、顶得每步都痛：** 野外医学常用口径是：消毒后用细针从边缘引出液体，**留下泡皮当生物敷料**，再盖清洁敷料（SH04）。本 skill 只转述，不指导现场手术。做不到无菌、或是血泡 → **不要自己剪开**，减负荷，就医或赛会医疗。

**血泡：** 多因更深的剪切。不要撕顶。减压、覆盖、停跑。甲下血肿剧痛 → 医务人员处理，不要用烧热的回形针在对话里教学。

**泡皮已经破：** 用干净水冲洗，保留还能盖住的皮，非粘敷料。泥浆越野尤其注意感染。

**黑趾甲：** 多数会自己长出去。甲松动、渗脓、红肿热 → 停跑就医。不要为了「好看」自行拔甲。

课后：洗脚擦干，湿鞋烘干再穿。下堂课若仍跛，走回归树 S1–S2，不要上越野长下坡。
