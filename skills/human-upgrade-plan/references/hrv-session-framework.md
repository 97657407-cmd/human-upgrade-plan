# HRV / 手表恢复分：怎么改今天的课

核验日期：2026-10-22。证据：[hrv-session-core](evidence/hrv-session-core.md) HV01–HV05。佳明点选：[garmin-recovery](garmin-recovery.md)。华为夜间 HRV：[huawei-mcp](huawei-mcp.md) `get_hrv_stats`（原样，不换单位）。  
**不是过度训练诊断。** 发烧、跛、胸痛仍走开课闸门/回归树；表绿不能放行。

有晨间 HRV、准备度、Body Battery、恢复%、或用户口述「今晚 HRV 偏低」时加载。无表继续用睡眠+主观+上次课，不编恢复分。

---

## 0. 先分清三样东西

| | 是什么 | 今天怎么用 |
|---|---|---|
| 研究里的 HRV | 多为晨间或课后指定分钟的 RMSSD/高频 | 只迁「相对自己、看趋势」 |
| 厂商准备度 / Body Battery / 恢复% | 黑箱模型 | 一档输入，单独不够改课（HV01、HV03） |
| 主观 + 睡眠 + 上次课 | 仍是主闸门 | 表和人对着才砍 * |

禁止：从腕式心率自己算 RMSSD；把别人的「正常分」套过来；一晚低分诊断过度训练。

---

## 1. 今天这堂课怎么改（抄进教案）

先读上次课。昨天刚 * 或长课，今早 HRV 偏低可以是 HV05 的正常拖尾。

| 组合 | 质量课（*） | 轻松/长课 |
|---|---|---|
| 表绿或 HRV 相对这周不差，人正常、无跛无烧 | 按计划 | 按计划 |
| **一晚** HRV/准备度偏低，睡眠够、主观还行 | **不自动砍**（HV01） | 按计划 |
| 相对自己基线 **连续 2 天**明显偏低 **并且** 主观差或睡眠差 | 改轻松或休（迁 HV04 理念，不抄其周结构） | 可保留短轻松 |
| 表很好，但跛、发烧、夜痛 | 停诱发 | 听症状 |
| 表很好，但昨天质量后腿很沉、热身已喘 | 砍 *（HV05 + 热身反馈） | 可轻松 |

「相对自己」：有佳明则看本周 summaries，不要只看 `lastNightAvg` 一个数（见 garmin-recovery）。没有连续晨测 → 信息不足，不装精确。

---

## 2. 教案格

```text
**恢复输入**
来源：口述 / 高驰 / 佳明 / 华为（准备度时刻：起床或运动前）
HRV或准备度：相对这周 偏低一晚 / 连续偏低 / 不差 / 未知
主观与睡眠：
判定：按计划 / 砍 * / 停
```

钉卡：一晚低分用 HV01；分不清好坏用 HV03；昨天刚狠用 HV05。不要一次钉 5 张。
