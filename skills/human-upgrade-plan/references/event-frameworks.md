# 项目需求与课型选择

这是通用教练框架，不是针对任何个体的课表。先确定当前能力与组织耐受；具体配速、跑量、组数须另行个体化。引用文献前先走 [知识与证据](training-knowledge-system.md) 的核验状态；未核验题录不能直接当剂量依据。

| 项目 | 主要表现需求 | 常用训练模块 | 重点观察 |
|---|---|---|---|
| 100m | 起跑、加速、最高速度及保持 | 起跑技术、短加速、行进间跑、力量与弹性 | 分段速度、动作稳定、重复质量；纯速度课不以喘或累为目标 |
| 200m | 加速、弯道控制、速度保持 | 弯道技术、直道最高速度、短速度耐力 | 弯道半径/道次、左右侧暴露；不从极小半径研究直接复制标准跑道剂量 |
| 400m | 速度储备、较长高速维持、配速分配 | 最大速度、速度耐力、专项耐力、力量 | 分段与动作衰减；乳酸数值不能单独定义课的收益 |
| 800m | 速度储备、有氧支撑、专项耐受与战术 | 短速度、有氧、不同长度间歇、专项配速、力量 | 按速度/耐力优势分型；避免把全部训练变成高疲劳重复跑 |
| 1500m | 有氧功率、经济性、专项速度和末段变速 | 有氧、阈值、较高有氧强度间歇、速度维护 | 区分计时赛与战术赛，观察末段动作及速度储备 |
| 3000m | 高有氧速度、经济性、持续高强度能力 | 低强度基础、阈值、有氧功率、比赛节奏 | 工作段时间与恢复决定刺激；急性心率不是长期效果 |
| 5000m | 有氧容量、阈值、经济性与变速 | 轻松跑、阈值、比赛强度间歇、速度与力量 | 强度分布、重复配速、恢复成本；不用远期目标强压长间歇 |
| 10000m | 有氧容量、阈值附近能力、经济性和配速稳定 | 容量、阈值、长一些的专项工作、速度维护 | 环境与后程衰减，避免每次有氧跑都变中高强度 |
| 半程马拉松 | 高比例有氧能力维持、耐久性、补给与节奏 | 轻松跑、长跑、阈值/专项节奏、力量维护 | 疲劳后速度与动作；当前专项配速需依据近期数据 |
| 马拉松 | 长时间耐久性、燃料与胃肠耐受、配速策略 | 渐进容量、长跑、专项配速、补给模拟、减量 | 周负荷、最长暴露、供能与环境；不照搬精英长跑 |
| 越野 | 地形适应、上坡输出、下坡离心耐受、补给与技术 | 按时间/爬升排课、渐进下坡、专项力量、装备练习 | 距离之外记录升降、路面、技术难度；不等同平路公里数 |

## 阶段组织

入门/中断后逐渐建立基本频率和低剂量项目动作；基础期扩充支持能力；专项期集中发展比赛关键需求，同时维持其他能力；赛前按个人疲劳管理减量；赛后重新评估。阶段长度随目标、现能力、病伤和生活调整。

800m转长跑时可保留短速度与力量，但逐渐增加有氧持续能力和耐久性；长跑转800m时逐步增加高速暴露、技术和力量需求。是否兼顾多个比赛以恢复资源和赛事优先级决定。

## 力量与弹性

根据经验选择蹲、髋铰链、单腿支撑、推拉、核心与足踝等动作类别。技术陌生时用可控制的变式，不因目标爆发力就要求高翻。增强式和高速跑均是冲击负荷，应进入总负荷记录；熟悉动作、当前症状与次日反应决定进阶。主目标若是增肌而非比赛，改用 [力量模式](strength-training-modes.md) 的模式 D/C，不要套田径维持剂量。项目配比与动作菜单见该文件。

## 生理概念

供能系统共同参与运动；距离越短不等于完全无氧。VO₂max是摄取利用氧的最大速率，跑步经济性是同速度的能量成本，阈值/临界速度是强度边界的不同测量概念，不能随意互换。速度储备依赖所用速度测试与定义；耐久性关注疲劳后性能是否改变。

## 教练成长

学习顺序可为：生理概念 → 负荷与恢复 → 本人/授权个案复盘 → 主项目课型 → 周期化与测试 → 其他项目转换。每次用一篇证据回答一个训练判断，再检查实际反应。文献和skill辅助判断，不能替代长期现场观察与必要的临床/营养协作。
