# 中国田径运动员技术等级成绩（对照用）

核验日期：2026-10-12。  
来源：国家体育总局《运动员技术等级标准》田径部分，体竞字〔2024〕121 号，**2025-01-01 起施行**（以比赛结束时间为准）。附件曾于 2024-11-18 更新。证据卡：[cn-athletics-grades-core](evidence/cn-athletics-grades-core.md)。

**这不是课表，不是校园体测及格线，也不是「手表跑进这个成绩就算该级运动员」。**  
达标只发生在标准列出的比赛、计时和风速条件下，由体育行政部门按办法授予。本表只给对话里对照：用户说冲二级/一级/健将、或拿路跑成绩问「算哪一级」时打开。

五级从高到低：**国际级运动健将 → 运动健将 → 一级 → 二级 → 三级**。跑表成绩越快越好；跳跃投掷越远/越高越好。`—` 表示该级不设该项。

排课仍走金样与闸门。旧等级证、多年前的达标赛，都不是现能力。

## 0. 什么时候用

| 用户说的 | 怎么用本表 |
|---|---|
| 建档已问性别 | `boy` 用第 1 节，`girl` 用第 2 节。其他/未告知则两行都写 |
| 想考二级、冲一级、有没有健将水平 | 对照对应项目；说明还要在规定比赛里电计/感应计时跑出来 |
| 路跑 PB 问算几级 | 只对照半马/马拉松行；操场项目不要用路跑配速硬换 |
| 校队 / 高水平招生口语 | 可把目标钉在一级或健将附近，课仍按近 8 周真实训练排 |
| 大众完赛、校园 50/800/1000 体测 | **不要用本表**。体测走短跑手册 / 金样 5 |

禁止：把三级当「普通人应该跑到」；用国际级数字给爱好者排间歇；手计时、顺风超 2 m/s、跑步机、越野赛成绩去套操场项。

需要测风速的项目：100 米、200 米、跳远、三级跳远、男子 110 米栏、女子 100 米栏。跑进方向风速 **>2 m/s 不得授予**。马拉松/半马为感应计时；场地跑为电计。

## 3. 对话里怎么改课（对照完立刻回来）

1. 先问项目、性别、年龄组、是操场电计还是路跑感应、有没有顺风。对不上就不给「已经是二级」。  
2. 目标钉在某一级时：大众仍用金样，不抄国家队周跑量。离二级还差很多 → 先连续性，不每堂按二级配速练。  
3. 已接近二级/一级、且在正规比赛窗口：备赛走 [race-prep-framework](race-prep-framework.md)，标签用校队/进阶，不升成精英。  
4. 全能、竞走团体、马拉松团体里跑出单项标准，标准允许按单项授予——对话里仍要核对赛事资格，本 skill 不代办申请。

修订后的总局标准会改数字。再用时先核体竞字是否仍是〔2024〕121 号、施行日是否仍从 2025-01-01 起。
