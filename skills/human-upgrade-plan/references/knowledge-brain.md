# 知识大脑（决策时先加载）

把全库压成判断。给用户建议时：**先过本文件 → 再套框架手册产出课表 → 最后用 INDEX-all 钉 1–2 张卡写「为什么」**。

用户觉得建议牛，是因为取舍清楚、剂量可执行、边界诚实；不是因为把 92 条入口贴进对话。

细卡仍在 [INDEX-all](evidence/INDEX-all.md)。本文件禁止发明未入库的组次或效果量。

---

## 0. 决策优先级（不可颠倒）

1. **红旗与功能**：胸痛/晕厥/气短、跛、肿、夜间骨痛、跟腱枪响 → 停诱发课，走回归树。手表「恢复 90%」不能放行。
2. **睡眠与生活能不能撑住这堂课**：困、考试周、夜班、漏饭 → 先砍质量课，不先加课。
3. **主目标只有一个**：跑成绩 / 增肌 / 伤后 / 健康能练。互斥目标当面选，不排「又马又巨腿」满分周。
4. **本周只做一个主刺激**：一次质量跑或一次下肢硬力量，其余服务恢复。下周只改一个变量。
5. **场地决定动作**：有什么器械写什么；没有就不写杠铃。
6. **文献为当前这一刀服务**：从大脑选原理，从索引钉卡，不先搜论文再发明课表。

旧 PB、预测成绩、Stryd 功率、VO2max 手表分 → 缩小未知，不当处方。

## 1. 跨项目皮层（永远生效）

**适应来自可重复完成，不是来自单次狠。** 完成率、次日还能走路、关键课动作不散，比「感觉练到了」重要。忙碌周减总量，不改成更多 HIIT 补偿。漏课重排，不堆周末。

**睡眠是适应开关。** 睡眠干预对表现有信号，但研究偏倚高、样本小；缺觉会伤急性表现。连续睡眠差 → 取消带 * 的课。不靠咖啡硬上关键课。Overreaching 可能让客观睡眠效率略降，不能用睡眠分诊断过度训练。

**精神累 ≠ 身体还能上强度。** 精神疲劳会抬 RPE、让人觉得更难；大脑耐力训练不是上班族默认作业。下班后先 5–10 分钟轻松活动再决定，不要默认「活动开了就上间歇」。

**久坐要打断，但那不是训练。** 办公室干预大约能少坐几十分钟，对提速/减脂几乎不自动兑现。课表里写「课间起来走」，不要承诺因此 5K 更快。零食式运动（短积量）适合没时间的健康体能，不替代专项质量课。

**跑 + 力量有干扰，主要咬下肢最大力量（男性证据更清楚），肥大证据不足。**  
- 要跑：力量服务跑，下肢硬课不紧接质量跑。  
- 要围度：砍耗竭有氧，容量优先。  
- 两个都想要：承认两边都是「良好」；硬课错开；上肢干扰小，可放轻松跑日。  
排序（先力后氧）不如总量和恢复重要。忙时上肢可用拮抗超组省时间；腿保持传统组间。

**冰浴换的是明天能练，不是每次力量课后的肥大仪式。** 涨力量/涨围阶段别当日常；赛会密集日可以用。

**防伤力量值得每周做一小份，但不保证零伤。** 能完成的髋、单腿、小腿、抗旋转，优于复杂预防计划。痛了换模式减冲击（力量第 9 节），不热开了硬顶。

**强度分布没有唯一神教。** 极化 vs 金字塔，在 VO2max 和计时上总体未见谁必胜；业余先保证大量能说话的跑 + 每周 ≤1 次真正质量。不要给入门选手排挪威双阈值。

**供能系统同时在工作。** 短距离不是纯无氧；VO2max、经济性、阈值/临界速度不是同一个东西，禁止用一个手表区代替三个概念。

**女选手：** 铁、相对能量不足走营养包口径，补铁必须医嘱。经期对训练可自愿说，不强迫。不要用男性同期干扰数据假装已经覆盖她。

**补剂与碳水：** 比赛日高碳水要练胃，不靠赛晨突然 90g。肌酸对耐力不是万能。饥饿跑、LEA 先加饭和减课，不先加间歇。

## 2. 项目皮层（100m → 越野）

排课骨架仍用框架手册金样；这里只定「什么算这项目的牛逼取舍」。

### 100 / 200 / 400

赢在最后两趟还干净，不在累计喘。主课：短加速、弯道/速度保持、重力量或弹性（二选一放腿）。少做：长乳酸堆、下肢力竭超级组、用慢跑当短跑训练。大众中断后：先动作和加速度，不先计时。

### 800 / 1500

大众先补有氧底 + 最大速度，再谈专项乳酸。精英框架是高有氧底 + 速度储备 + 专项块，不能照抄量。周结构像金样 2：一节短加速、一节有氧功率轻（如短 VO2 段）、力量维持。4×4 是摄氧工具，不是 800 的日常主食。阈值数字不能单独定义课的收益。

### 5K / 10K

主刺激每周最多 1 次（节奏/短间歇），其余能说话。力量 1 次低量高质（单腿、髋、小腿）。上班族用金样 1，不要用精英周跑量。零食式运动只能填「没时间的健康」，不能冒充 5K 专项。

有比赛日期时，先按 [备赛框架](race-prep-framework.md) 给阶段地图（大众/进阶/体测降级），再写本周。不要给爱好者抄精英周跑量。

### 半马 / 马拉松

长课按时间，不按比赛配速练。阈值是「舒适偏难」可说话短句，不是比赛配速彩排（赛前专项周另说）。补给、碳板、胃肠耐受要单独练，不靠鞋科技当训练。赛前 3 周减冲击，不用金样 4 当减量。相对能量不足优先于再加长课。全马要快：大数据里快者是**更多轻松体积**，不是更高强度占比（RP22）；大众不追 2:xx 的周公里。

### 越野

路跑强 ≠ 越野强。限制因素是爬升经济性、下坡离心、技术路段神经肌肉，不是平路 VO2max。长课按时间+爬升；下坡单排不满量；力量加重单腿与离心。首野先完赛。狠下坡后约 4 天再排质量。长野/超马最后 1–2 周要明确减负荷；短野不必同样砍。

## 3. 生活皮层

| 画像 | 大脑默认 |
|---|---|
| 学生/上班，时间碎，要能跑 | 金样 1；质量课放精力最好的晚上或周末上午；久坐用打断，不另加工课 HIIT |
| 考试周/出差/夜班 | 保睡眠与轻松；取消 * 课；回来不补债 |
| 只有操场/马路 | 质量用时间+RPE，不写跑道道次玄学 |
| 只有跑步机 | 间歇可做；长课用时间；坡度代替部分下坡但不是越野 |
| 宿舍弹力带 | 力量改铰链、分腿、推拉带、提踵；不写高翻 |
| 健身房要围度 | 金样 3 / 模式 D；有氧上限写死 |
| 高驰已接入 | 先对实际完成再改下周；写回日历必须再确认 |
| 无表 | 时间、RPE、症状、睡眠四件套足够排课 |

上午 vs 下午有氧：有代谢研究，但不给「必须下午练」的宗教。按能睡着、能吃上饭的时段放关键课。

## 4. 冲突裁判（用户一开口就先判）

| 用户要的 | 你给出的 |
|---|---|
| 又要马又要腿围暴涨 | 选主目标。马年：力量维持。围度年：跑量砍到健康有氧。 |
| 这周没练想周末补四堂 | 否。重排 1–2 堂，不补债。 |
| 手表说恢复满，但腿跛 | 听跛。 |
| 想练挪威/极化/4×4 因为网上火 | 看阶段。入门与回归：否。有稳定有氧底再给 1 次有氧功率，并钉卡说明边界。 |
| 每天冰浴/每天 HIIT | 否。冰浴看目的；HIIT 每周至多一次质量位。 |
| 疼但想「活动开」 | 走回归树。尖锐/次日加重 → 停。 |
| 要精确配速但没有近期测验 | 给 RPE/能说话分支，不编假配速。 |
| 问「我 VO2max 多少区该跑」 | 拆开概念：轻松能说话；质量课另定义；不把厂商 VO2max 当区。 |

## 5. 什么叫最牛的一条建议

必须同时做到：

1. **有名字的周骨架**（金样几、模式几），不是七天灵感。  
2. **有一个主刺激、一个取消条件、一个下周只改的变量。**  
3. **动作用户今天能做。**  
4. **为什么分三层**：生理上一句、文献一句（带深度和「不能外推到你的地方」）、针对此人一句。  
5. **如果信息不够：给条件分支**（若睡眠 <6h 则…），不装已知。

禁止：堆 5 篇论文、保证无伤或 PB、用旧成绩开间歇、把增肌菜单塞进 5K 金样、把越野写成平路公里数。

## 6. 本轮加载顺序

1. 建档缺口 ≤3 个问完。  
2. 用本文件 §0–4 做出判断（类型、砍什么、主刺激是什么）。  
3. 用 [框架手册](framework-handbook.md) 写成七天。  
4. 用 [INDEX-all](evidence/INDEX-all.md) 的项目/关键词钉 **1–2 张**最相关卡。  
5. 按 [输出格式](output-patterns.md) 交；告诉下次回报什么。

学习论文模式：跳过「少引用」，按 INDEX-all 展开，但仍用本文件的皮层解释「所以改哪一个训练变量」。
