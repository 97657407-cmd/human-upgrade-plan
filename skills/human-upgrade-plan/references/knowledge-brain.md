# 知识大脑（决策时先加载）

把全库压成判断。给用户建议时：**先过本文件优先级 → 再打开 [决策流](decision-flow.md) 只选一条树（复跑 / 无锚点 / 大师 / 备赛 / 金样）→ 再套框架手册产出课表 → 最后用 INDEX-all 钉 1–2 张卡写「为什么」**。

用户觉得建议牛，是因为取舍清楚、剂量可执行、边界诚实，并且课表读起来像当天教案（课的目的 + 准备/基本/结束 + 点名有出处的教练理论）；不是因为把索引整表贴进对话。禁止编造名帅语录。

细卡仍在 [INDEX-all](evidence/INDEX-all.md)。本文件禁止发明未入库的组次或效果量。

## 0. 决策优先级（不可颠倒）

1. **红旗与功能**：胸痛/晕厥/气短、跛、肿、夜间骨痛、跟腱枪响、**发热/发冷/静息心悸** → 停诱发课。痛走回归树与 [伤病负荷手册](injury-load-framework.md)；膝外侧/胫骨内侧/髌前抄 [跑痛闸门](runner-pain-framework.md)。发烧走 [开课闸门](session-gate-framework.md)。夜间局灶骨痛按骨应力怀疑转介，不走 S2 走跑试。手表「恢复 90%」不能放行。
2. **睡眠、生病与空气能不能撑住这堂课**：困、考试周、夜班、漏饭、轻度感冒 → 先砍质量课。发烧/发冷/胸闷/静息心悸 → 停 * 课，不用脖子以上口诀。室外课查 **PM2.5 μg/m³**（中国 AQI ≠ 美国 AQI；禁止抄「150」）。病假回来按空窗接训（闸门 1.1），不接旧配速。
3. **主目标只有一个**：跑成绩 / 增肌 / 伤后 / 健康能练。互斥目标当面选，不排「又马又巨腿」满分周。
4. **本周只做一个主刺激**：一次质量跑或一次下肢硬力量，其余服务恢复。下周只改一个变量。
5. **场地决定动作，地点天气和空气决定热身、穿搭与能否室外**：有什么器械写什么。写课前确认**几点练**，小时预报用北京时间对齐窗口；有雨先给多套方案让用户选（[下雨时段](rain-window-framework.md)），不擅自改健身房。室外课抄 [跑步穿搭](run-clothing-framework.md)（质量课少一层，组间/练后穿回来，湿衣马上换）。室内跑步机按更热一档，用时间/RPE 不抄室外配速。
6. **文献为当前这一刀服务**：先选定决策流那一条树，再从索引钉 1–2 张卡，不先搜论文再发明课表。质量课必须写强度锚点（无场测用 RPE 句，不编配速）。

旧 PB、预测成绩、Stryd 功率、VO2max 手表分、多年前的等级证 → 缩小未知，不当处方。用户问二级/一级/健将时打开 [中国田径等级成绩](cn-athletics-grades.md) 对照，课仍按近况排。

## 1. 跨项目皮层（永远生效）

**适应来自可重复完成，不是来自单次狠。** 完成率、次日还能走路、关键课动作不散，比「感觉练到了」重要。忙碌周减总量，不改成更多 HIIT 补偿。漏课重排，不堆周末。

**睡眠是适应开关。** 睡眠干预对表现有信号，但研究偏倚高、样本小；缺觉会伤急性表现。连续睡眠差 → 取消带 * 的课。不靠咖啡硬上关键课。Overreaching 可能让客观睡眠效率略降，不能用睡眠分诊断过度训练。

**精神累 ≠ 身体还能上强度。** 精神疲劳会抬 RPE、让人觉得更难；大脑耐力训练不是上班族默认作业。下班后先 5–10 分钟轻松活动再决定，不要默认「活动开了就上间歇」。

**久坐要打断，但那不是训练。** 办公室干预大约能少坐几十分钟，对提速/减脂几乎不自动兑现。课表里写「课间起来走」，不要承诺因此 5K 更快。零食式运动（短积量）适合没时间的健康体能，不替代专项质量课。

**跑 + 力量有干扰，主要咬下肢最大力量（男性证据更清楚），肥大证据不足。**  
- 要跑：力量服务跑，下肢硬课不紧接质量跑。  
- 要围度：砍耗竭有氧，容量优先。  
- 两个都想要：承认两边都是「良好」；硬课错开；上肢干扰小，可放轻松跑日。  
排序（先力后氧）不如总量和恢复重要。忙时上肢可用拮抗超组省时间；腿保持传统组间。

**冰浴换的是明天能练，不是每次力量课后的肥大仪式。** 涨力量/涨围阶段别当日常；赛会密集日可以用。

**防伤力量值得每周做一小份，但不保证零伤。** 能完成的髋、单腿、小腿、抗旋转，优于复杂预防计划。没有普适 10% 加量公式。痛了换模式减冲击（[伤病负荷手册](injury-load-framework.md) + 力量第 9 节），不热开了硬顶。

**热身服务这一堂课、这一类人、这一处天气，课表不能省。** 写课前检索该地点预报。套 [热身与练后手册](warmup-recovery-framework.md)：大众短热身，专业才完整 RAMP。热身不是零伤保证（IWR33）。冷天加 Raise（IWR31）；热天/很湿缩短，核心先烧热则耐力更短（IWR32/34）。热完已喘就下一堂砍热身。

**赛日看天气和身体，不看愿望配速。** 热了就降档（慢者掉得更多，RP24/28）；公式推全马偏快（RP25）；前半不要赚时间（RP26）。操作手册：[赛事预测与赛日策略](race-day-strategy.md)。手表预测只是一档输入。先读上次课。

**强度分布没有唯一神教。** 极化 vs 金字塔，在 VO2max 和计时上总体未见谁必胜；业余先保证大量能说话的跑 + 每周 ≤1 次真正质量。不要给入门选手排挪威双阈值。

**供能系统同时在工作。** 短距离不是纯无氧；VO2max、经济性、阈值/临界速度不是同一个东西，禁止用一个手表区代替三个概念。需要配速锚点时走 [临界速度/场测](critical-speed-framework.md)：CS 与 CP 二选一；灰区留缓冲；无场测用说话轻松 + RPE。

**大师组先保量与力量，不靠加 HIT 抗衰老。** 纵向里训练量塌了，VO₂ 掉得更快（[大师组](masters-run-framework.md)）。旧 PB 不作处方。

**先问性别再对照表。** 建档原句：`boy / girl，或其他选项？` boy→男子列；girl→女子列（铁、相对能量不足，补铁必须医嘱；经期自愿）。其他/不答：通用金样，对照等级写两行。不要用男性同期干扰数据假装已经覆盖女选手。

**补剂与碳水：** 比赛日高碳水要练胃，不靠赛晨突然 90g。肌酸对耐力不是万能。饥饿跑、LEA 先加饭和减课，不先加间歇。

**热天喝水：口渴喝，禁止灌到体重涨。** 大众不要每 15 分钟强制毫升。手肿、越喝越头痛 → 停，不再给水。操作：[补水与咖啡因](hydrate-caffeine-framework.md)。

**咖啡因给质量课和比赛，不给轻松日。** 约 3–6 mg/kg，开跑前约 60 min，必须先在训练试过。晚上要睡觉就不用。不能用来硬扛发烧或睡眠债。

## 2. 项目皮层（100m → 越野）

排课骨架仍用框架手册金样；这里只定「什么算这项目的牛逼取舍」。

### 100 / 200 / 400 / 体测 50

赢在最后两趟还干净，不在累计喘。排课抄 [短跑手册](sprint-framework.md)：先写课的目的（加速 / 最高速度 / 专项耐力）。体测 50/100 = 加速 + 力量，不要 150 m 力竭。前 20 m 推地快频率，再打开步幅；不要全班统一加大步。少做：长乳酸堆、70–95% 灰区冲、球类短休、下肢力竭超级组、起跑器量脚当主课。100/200 短到长；400 可略长到短但仍先加速干净，不要四个 100 m 全力。腘绳肌在提速窗口减量，高速日保持新鲜。各国教练只迁理念（Mills 放松、Pfaff 极化、Smith 轻松分段、Tellez 少减速、Huntington 加速优先、Botha 听身体、袁国强先看动作、Hart 从量到质、土江比赛模式、孙海平效率）。禁止抄名人课量。

### 800 / 1500

大众先补有氧底 + 最大速度，再谈专项乳酸。精英框架是高有氧底 + 速度储备 + 专项块，不能照抄量。周结构像金样 2，课形从 [中跑课形](middle-distance-framework.md) 只降级一行：基础期短加速 + 至多 1 次阈值或摄氧。乳酸耐受/产生放备赛窗。4×4 是摄氧工具，不是 800 的日常主食。上坡准备期可用，不神化（[上坡](hill-run-framework.md)）。跑加力量先错开硬课，蛋白大约 1.6 g/kg 分餐，不靠 3.2 g/kg 取消干扰（[同期能量](concurrent-fuel-framework.md)）。

### 5K / 10K

主刺激每周最多 1 次（节奏/短间歇），其余能说话。力量 1 次低量高质（单腿、髋、小腿）。上班族用金样 1，不要用精英周跑量。零食式运动只能填「没时间的健康」，不能冒充 5K 专项。

有比赛日期时，先按 [备赛框架](race-prep-framework.md) 给阶段地图（大众/进阶/体测降级），再写本周。不要给爱好者抄精英周跑量。

### 半马 / 马拉松

长课按时间，不按比赛配速练。阈值是「舒适偏难」可说话短句，不是比赛配速彩排（赛前专项周另说）。补给、碳板、胃肠耐受要单独练，不靠鞋科技当训练。鞋抄 [碳板/比赛鞋](carbon-shoe-framework.md)。去热的比赛抄 [热习服](heat-acclimation-framework.md)，减量周不新上桑拿。高原赛抄 [高原比赛](altitude-race-framework.md)，不开住高练低。赛前 3 周减冲击，不用金样 4 当减量。相对能量不足优先于再加长课。全马要快：大数据里快者是**更多轻松体积**，不是更高强度占比（RP22）；大众不追 2:xx 的周公里。  
赛日：三档预测走 [赛日策略](race-day-strategy.md)；**几公里吃胶、水、盐丸**走 [赛道补给](race-fuel-framework.md)。碳水按时长不按体重；未练胃不上 90 g/h；盐丸默认不用（低钠主因是喝多了，抽筋不是缺盐丸）。前半不要赚时间。

### 越野

路跑强 ≠ 越野强。限制因素是爬升经济性、下坡离心、技术路段神经肌肉，不是平路 VO2max。训练抄 [越野落地](trail-session-framework.md)。赛日拆道和检查点抄 [越野赛事补给](trail-race-framework.md)：不抄公路 90 g/h，前几爬走合法。长课按时间+爬升；下坡单排不满量；力量加重单腿与离心。首野先完赛。狠下坡后 **1–2 天**不上质量（习惯者次日仍可能有神经肌肉改变）。长野/超马最后 1–2 周要明确减负荷；短野不必同样砍。杖给陡爬走，不给平路。

### 青少年（大约 U18）

不抄成人金样周公里，也不把北京体考满分当二级运动员。适跑距离证据弱（YR01）。有组织训练小时先别超过年龄岁数；留玩耍；每周真休息（YR03、YR04）。监督下力量可低量（YR02）。**默认不排超马**（YR05）。夜痛、漏饭、闭经走成人同一套闸门，不「抗一抗」。

## 3. 生活皮层

| 画像 | 大脑默认 |
|---|---|
| 学生/上班，时间碎，要能跑 | 金样 1；质量课放精力最好的晚上或周末上午；久坐用打断，不另加工课 HIIT |
| 女选手（已告知） | 金样骨架同性别不改项目；周剂量走 [女选手周](female-week-framework.md)；铁/LEA 先加饭砍 *；等级对照用女子表；经期不适日转低负荷，不强迫汇报经期；不按黄体期公式配速 |
| 未告知性别 | 通用金样；等级对照写男女两行 |
| 考试周/出差/夜班 | 保睡眠与轻松；取消 * 课；回来不补债 |
| 只有操场/马路 | 质量用时间+RPE，不写跑道道次玄学 |
| 只有跑步机 | 间歇可做；长课用时间；坡度代替部分下坡但不是越野 |
| 宿舍弹力带 | 力量改铰链、分腿、推拉带、提踵；不写高翻 |
| 健身房要围度 | 金样 3 / 模式 D；有氧上限写死 |
| 高驰 / 佳明已接入 | **排课前先读上次运动+睡眠**；接了几块读几块；再决定今天执行/降档/休息；写回日历必须再确认 |
| 无表 | 时间、RPE、症状、睡眠四件套足够排课 |
| 有胸带/臂带/豆 | 每堂提醒出门戴；先按他最爱的；间歇加胸带、越野加豆；秋冬打湿电极 |

上午 vs 下午有氧：有代谢研究，但不给「必须下午练」的宗教。按能睡着、能吃上饭的时段放关键课。

## 4. 冲突裁判（用户一开口就先判）

| 用户要的 | 你给出的 |
|---|---|
| 又要马又要腿围暴涨 | 选主目标。马年：力量维持。围度年：跑量砍到健康有氧。 |
| 这周没练想周末补四堂 | 否。重排 1–2 堂，不补债。 |
| 手表说恢复满，但腿跛 | 听跛。 |
| 想练挪威/极化/4×4 因为网上火 | 看阶段。入门与回归：否。有稳定有氧底：4×4 给 1 次有氧功率（[间歇休息](interval-rest-framework.md)）；双阈值只给进阶且默认**单阈值**起步（[双阈值](double-threshold-framework.md)）。 |
| 间歇歇越短越科学 / 骑车 60 s 歇原样贴跑步 | 否。先定目的（摄氧 vs 速度 vs 重复冲刺）。跑冲击大于骑；跨项目恢复期摄氧回落不同。抄 [间歇休息](interval-rest-framework.md)。 |
| 要双阈值 / 一天两次阈值抄 Jakob | 否（入门/回归/周跑不稳）。最多周 1 次单阈值间歇。有底子也先两个**分开的**阈值日，不默认同日两次。钉 DT08；案例见 [elite-cases](elite-cases-framework.md) EC03。 |
| 要抄基普乔格 15×1000 / 周 200 km | 否。只借「一天质量、长课与间歇分日」。钉 EC06/EC10。 |
| 要抄 800/1500 冠军的 8×1000 或一周三四次强度 | 否。一周一个主刺激，课形降级（MD01/MD06）。 |
| 上坡短冲当力量或 VO2 特效 | 否。可用作准备期短工具。meta 合并效应不显著（HL01）。 |
| 蛋白吃到 3.2 g/kg 就能跑加力量两边满分 / 空腹上质量课 | 否。约 1.6 g/kg 分餐够用起点；硬课错开；关键课当天有碳水（CF02–CF04）。 |
| 每天冰浴/每天 HIIT | 否。冰浴看目的；HIIT 每周至多一次质量位。 |
| 疼但想「活动开」 | 走回归树。尖锐/次日加重 → 停。 |
| 感冒了但想上间歇 / 脖子以上就能练 | 否。发烧停跑。无旗标也先短走跑试探，当天不上 * 课。 |
| 病了一周想按旧配速接间歇 | 否。按闸门 1.1 空窗接训；2–4 周当重建。 |
| 雾霾天还按公路配速 | 查 PM2.5 μg；差则室内时间/RPE，不抄公路配速。禁止把美国 AQI 150 套到国内 App（中国 AQI 150 ≈ 115 μg，EPA 150 ≈ 55 μg）。 |
| 冬天怕感冒就裹成球开跑 / 间歇后湿着吹风聊 | 开跑按跑步穿，场边留外套。湿衣隔热会塌。围脖挡干冷气道。不能保证不病毒感染。 |
| 要精确配速但没有近期测验 | 给 RPE/能说话分支，不编假配速。要锚点再约场测周（[临界速度](critical-speed-framework.md)）。 |
| 用临界速度就等于能无限跑 / 同周混 CS% 与功率 CP% | 否。CS 是域界不是轻松配；灰区留缓冲；体系二选一（CV02/CV07）。 |
| 年纪大了多堆 HIIT 抗掉速 | 否。先维持可完成周跑与力量；量塌才是 VO₂ 大掉的常见原因（大师组 MR01）。 |
| 骨应力刚好一点就按旧配速间歇 | 否。未临床放行不排走跑；放行后走跑、先距离后速度；禁止恢复分放行（RI06–08）。 |
| 问「我 VO2max 多少区该跑」 | 拆开概念：轻松能说话；质量课另定义；不把厂商 VO2max 当区。 |
| 只有腕表就要按心率区跑间歇 | 否。腕式短窗口误差大。有胸带戴胸带；没有用时间+RPE。 |
| 热天每 15 分钟必须灌 400–800 ml | 否。大众口渴喝。体重涨了就是喝多了。 |
| 赛晨第一次试咖啡因 / 轻松日也要氮泵 | 否。3 mg/kg 起，先在 * 课试。轻松日不用。晚上默认不用。 |
| 手表跑进三级/二级就要按健将练 | 否。等级表只对照。授证要规定比赛+电计/感应+风速。课按近 8 周真实训练。 |
| 北京中考 1000 米按二级运动员练 | 否。2026 学考现场满分大约 4:05/3:55（良好即满分），走北京体考手册。 |

## 5. 什么叫最牛的一条建议

必须同时做到：

1. **有名字的周骨架**（金样几、模式几），不是七天灵感。  
2. **有一个主刺激、一个取消条件、一个下周只改的变量。**  
3. **动作用户今天能做。**  
4. **为什么分三层**：生理上一句、文献一句（带深度和「不能外推到你的地方」）、针对此人一句。  
5. **如果信息不够：给条件分支**（若睡眠 <6h 则…），不装已知。

禁止：堆 5 篇论文、保证无伤或 PB、用旧成绩开间歇、把增肌菜单塞进 5K 金样、把越野写成平路公里数。

## 6. 本轮加载顺序

1. 建档缺口 ≤3 个问完（含称呼与性别；性别未答也可先排通用课）。  
2. **读上次课**（已接的高驰/佳明或口述）、睡眠、**上次热身反馈**、有无发热、最近是否病假空窗。确认今天在哪练、**几点练**，小时降水是否碰上该窗口（北京时间），并写穿搭。热天长课写饮水；* 课或比赛才写咖啡因。长课/比赛写补给。  
3. 用本文件 §0–4 做出判断（类型、砍什么、主刺激是什么）。  
4. 用 [框架手册](framework-handbook.md) 写成七天；**每堂写热身**（人群×天气）。长课必须写补给（[赛道补给](race-fuel-framework.md) 4.0）。越野加 [越野落地](trail-session-framework.md)。`girl` 加 [女选手周](female-week-framework.md)。有比赛加 [赛日策略](race-day-strategy.md) **和**赛道补给全文，输出赛事安排。跑着痛、走路可以：有氧改骑/椭圆，套 [交叉训练手册](cross-train-framework.md)，仍算负荷。  
5. 用 [INDEX-all](evidence/INDEX-all.md) 钉 **1–2 张**最相关卡。  
6. 按 [输出格式](output-patterns.md) 交；下次必问热身刚好/已喘/仍冷。

学习论文模式：跳过「少引用」，按 INDEX-all 展开，但仍用本文件的皮层解释「所以改哪一个训练变量」。
