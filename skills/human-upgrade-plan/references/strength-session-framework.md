# 力量日可抄课（A–F）

核验日期：2026-10-12。动作细节与伤变式仍读 [力量模式](strength-training-modes.md)。  
**主课只抄下面一张。** 与短跑手册相同：写目的，禁止把增肌腿日塞进 5K 周。

热身：5 min 走 + 主动作 1 组轻。RPE 6–7，下肢 RIR 2–3。技术不熟改哑铃/分腿/机器。质量跑次日不排 A/B/E 的跳。膝/跟腱/下背走力量第 9 节，不硬顶。

---

## 先选哪一张

| 人 | 抄 |
|---|---|
| 上班/学生 5K–半马，每周 1 次力量 | **A** |
| 100/200/400 或体测加速，重日 | **B** |
| 同上，快日 / 弹性 | **C** |
| 800 / 中长要速度储备 | **D** |
| 越野、有下坡 | **E** |
| 宿舍弹力带 / 没杠铃 | **F** |
| 主业增肌 | 不要用本表，用力量模式第 8 节 3/4 日 |

### A. 跑者维持（默认）

目的：髋膝踝能在轻松跑后还干活，不追围度。

1. 髋铰链或罗马尼亚硬拉 3×6–8  
2. 分腿蹲 3×6/腿  
3. 提踵直膝 2×10 + 屈膝 2×10  
4. 划船或弹力带划 3×8  
5. 可选：臀桥 3×8，或踝跳 2×6（跟腱不适删）

40–50 min。放轻松跑后或隔日。少做：腿屈伸力竭。

### B. 短跑重日

目的：支撑加速，与速度课隔开。

1. 深蹲或箱蹲 4×3–5  
2. 髋推或臀桥 3×5  
3. 北欧或腿弯举 3×4–6  
4. 推（卧推或推肩）3×5  
5. 划船 3×6  

少做：健美腿容量。腘绳肌紧：北欧改滑垫轻。

### C. 短跑快日

目的：短触地，质量掉就停。

1. 踝跳 3×8  
2. CMJ 或低栏 3×5  
3. 药球胸推或过头抛 3×5  
4. 提踵 3×6–8 控制  
5. Pallof 2×8/侧  

可放在加速课热身末，不要和下肢力竭同日。

### D. 800 / 中长力量

目的：速度储备 + 单腿，不改体重乱飘。

1. 杯式深蹲或深蹲 3×5  
2. 铰链 3×6  
3. 单腿蹲变式 3×5/腿  
4. 提踵 3×8  
5. 划船 3×8  

赛期每周 1 次。可选北欧 2×4。少做：追腿围。

### E. 越野离心 / 单腿

目的：下坡刹车。大下坡课后 48–96 h 不排本课。

1. 慢下分腿蹲或上台阶慢下 3×6/腿  
2. 单腿髋铰链 3×6/腿  
3. 提踵 3×8  
4. 抗旋转核心 2×8/侧  
5. 划船 3×8  

少做：只深蹲、忽视单腿离心。黑趾甲/水泡跛 → 改 F 或休息。

### F. 宿舍弹力带 / 只体重

目的：没杠铃也能维持。

1. 弹力带铰链或单腿桥 3×8  
2. 分腿蹲或弓步 3×8/腿  
3. 提踵 3×12  
4. 弹力带划船 3×10  
5. 死虫或侧支撑 2×20–30 s  

少做：发明高翻。

## 课表怎么写

`力量目的：A 跑者维持。抄本表 A，膝不适则铰链改臀桥、删跳。`

下周只改一个变量：某一主动作 +1 次或 +最小铃片。
