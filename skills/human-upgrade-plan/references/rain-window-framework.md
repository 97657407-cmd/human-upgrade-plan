# 开课闸门：几点下雨 × 几点能练（用户选，不代做决定）

核验日期：2026-10-12。穿搭仍走 [跑步穿搭](run-clothing-framework.md)；室内跑台走 [开课闸门](session-gate-framework.md) 第 3 节；骑/椭圆走 [交叉训练](cross-train-framework.md)。  
预报会错。雷暴、积水、能见度是安全问题，其余是「这堂课打不打折」。

**禁止：** 只写「今天有雨」；用早报气温代替开跑那一小时；没问几点练就改去健身房；替用户取消或替用户出门。

大陆用户钟点一律写 **北京时间**（例如 `北京时间 16:00–19:00 有雨`）。城市不在同一时区时写该市本地时并加北京时间对照。

---

## 0. 排今日室外课之前必须做完

1. **问清今天几点练**（可重叠问）：档案里的「早/晚」不够。原句：

   > 你今天想几点出门练？大概练多久？几点必须结束（上课/上班/接人）？这几个点能不能改？附近有没有能用的室内（跑台 / 骑 / 椭圆 / 力量）？

   档案已有常练时段：先复述「档案写的是晚上 19:00，今天还是这个点吗？」等他确认。未确认 → 先给**按时段的方案表**，请他选点，再把主课写死。

2. **检索该城市小时预报**，不要只查「今天阴」。至少拿到：每个整点的降水概率或降水描述、是否雷暴、气温、风、能见度（有则写）。检索失败：请用户打开天气 App 的**小时**页，报「你打算练的那两小时会不会下雨」。

3. 把 **他的窗口** 和 **下雨窗口** 叠在一起，用北京时间写进课表头。重叠才算「会淋到」；白天有雨、他 21:00 练且预报已停，不要用「今日有雨」吓唬。

课表头必须能看见钟点，例如：

`北京海淀 · 室外操场 · 北京时间 19:00–20:00 预报：小雨、12°C、东南风 3 级 · 16:00–19:00 雨较大 · 21:00 后转阴 · PM2.5 xx`

只写「有雨」不算交卷。

---

## 1. 雨有多大 → 这堂课打几折（仍由用户选）

| 他窗口里的预报 | 质量课（间歇/节奏/加速） | 轻松 / 长轻松 | 短跑计时 / 操场最快 |
|---|---|---|---|
| 干，或雨在窗口外 | 可按计划 | 可按计划 | 可按计划 |
| 毛毛雨 / 路面略湿、无雷 | **打折**：湿滑、心率易高、穿搭按更冷；能接受再出门 | 多数可跑，防滑、组后立刻换干衣 | **不建议计时**；改跨步或不计时加速 |
| 中到大雨、积水、风大 | 质量很难达标，算「练了但刺激不完整」 | 可改走跑或缩短；冷+湿+走 → 核心更易掉（穿搭 CL03） | 取消最快 |
| 雷暴、闪电、能见度很差、积水没过鞋 | **取消室外** | **取消室外** | 取消 |

打折的意思：同一组次在雨里完成，不等于干操场那堂课。下周不要假装这堂 * 已经吃满再加量。

雷暴：强烈建议室内或改期。仍把选项摆出来，等他回「那就室内」或「我改明天」。

---

## 2. 给方案，让他选（至少两套，常见四套）

先用一两句话说明重叠：`你说的 19:00–20:00，和北京时间 16:00–19:00 的雨会撞上后半段 / 正好错开。`

然后并列选项，**不要预先写死「所以去健身房」。** 每条写清：刺激还在不在、要什么场地、会不会占用明天。

**方案 1 — 仍在原窗口室外**  
适合：小雨、他接受打折、无雷。写穿搭（挡雨外层、场边干衣）、防滑、质量降一档或改轻松。取消条件：打雷、积水、脚底打滑就停。

**方案 2 — 挪到当天另一个干窗口**  
适合：预报有空档，且他 **能改点**。写北京时间「若你能 12:00 前 / 21:00 后出门」。问他能不能改；不能改就划掉此方案。挪点后若变成很晚，提醒睡眠（晚间质量 + 咖啡因默认不用）。

**方案 3 — 原窗口改室内（跑台 / 骑 / 椭圆 / 力量）**  
适合：窗口对上中到大雨或雷，或他有健身房。先问室内有什么。  
- 原课是轻松跑 → 跑台时间+能说话，坡 0%；或骑/椭圆同等时间（替换，不叠到明天再跑一遍）。  
- 原课是 * 质量 → 跑台保留段数和时间、RPE 对齐，不抄室外配速（闸门第 3 节）。短跑最大速度：室内直道不够就改跨步或改力量 B/C，不要在湿操场计时。  
- 原课是长跑 → 室内时间上限按他能接受的无聊程度砍，或骑更久；承认这不是公路长课。  
- 没有跑台只有力量房 → 抄 [力量 A–F](strength-session-framework.md) 一张，把今天的跑刺激记成「未完成，不补债硬堆明天」。

**方案 4 — 今天休息或只走，质量挪明天**  
适合：雷暴、他哪点都出不去、或打折后这堂课没有训练意义。明天不补两堂 *。

结尾固定问一句：

> 你选几？还是告诉我另一个能出门的北京时间，我按那个点重写一版。

他没回之前，不要只留一套「已改成健身房」的课表当最终答案。可以先把各方案的剂量都写好，方便他秒选。

---

## 3. 周计划里的雨

七天不要同一句「注意下雨」。每天按该天他的常练时段查；只有那一晚有雨的日子写方案枝。用户说「我只有晚上能练」→ 白天的晴不能拿来假装晚上不下雨。

---

## 4. 验收

下次问：最后选了哪套、有没有淋到、质量有没有打折。淋湿后立刻换干衣仍要写（穿搭手册）。未反馈不记「雨天也完成了 *」。
