# 交叉训练手册：自行车与椭圆机（康复 + 替代有氧）

核验日期：2026-10-11。  
证据：[xt-core](evidence/xt-core.md)。阶段门仍走 [伤后回归树](gold-weeks-and-return.md)。不是诊断。

跑者用骑/椭圆，多半是：**减冲击保有氧**，不是另开一项铁三专项。能无痛跑时，它们替不了跑步专项。

---

## 先选工具（痛什么、站不站得住）

| 情况 | 优先 | 原因 |
|---|---|---|
| 走路仍痛、夜间骨点、明显跛 | **停冲击**；能坐着无痛再骑；椭圆通常还要站 | 椭圆仍有体重支撑；骨应力怀疑先就医（IWR13） |
| 走得动、跑着痛 | 椭圆或骑都可以；椭圆更像直立、下肢肌电仍低于跑（XT02） | 心率可按该器械自己的峰值来配（XT01） |
| 膝下蹲/上下楼痛 | 骑：座位调高、少大齿比站踩；椭圆：阻力中等、少前倾死撑 | 痛了换姿势或换器械，不热开了硬顶 |
| 跟腱/足底 | 骑往往更省；椭圆足部仍有推蹬 | 晨起第一脚加重 → 停该器械冲击感 |
| 健康跑者只想减伤风险 | 可把 **1–2 次轻松跑**换成骑/椭圆（XT08），不要叠在满跑量上面（XT10） | 全换成骑/椭圆，3 km 会掉（XT04） |

冰水跑、泳池跑可作第三选项，本手册不展开。

---

## 科学模式（写进课表就这几条）

1. **保的是摄氧，不是比赛配速。** 短到中等窗口（约 3–5 周）用骑或椭圆替换跑步，VO2max / 乳酸阈常还能维持；3 km 成绩仍可能慢几十秒（XT03/XT04）。  
2. **从跑到骑的迁移大于从骑到跑**（XT05）。跑者伤停骑车，有氧掉得慢；骑手去跑，经济性不会自动变好。  
3. **强度用心率对应该器械**，不要拿跑步配速表去踩椭圆。同一 %HRmax，椭圆/踏步机与跑台的摄氧可以很接近（XT01）。  
4. **骑不长骨。** 长期几乎只骑，脊柱骨密度信号偏低；跑对腿骨更友好（XT07）。伤停冲击期间接受这件事，回归后要重新给骨头负荷，不是永远骑下去。  
5. **交叉仍算训练负荷**，不是休息。不要在已经跑满的一周再加一小时阈值骑。

### 剂量怎么抄（大众 vs 进阶）

| | 大众 / 伤后 S0–S2 | 进阶伤停（仍要保专项感觉） | 健康减冲击（能跑） |
|---|---|---|---|
| 频率 | 隔日 20–40 min，能说话 | 每周 4–6 次里用骑/椭圆填原轻松日 | 替换 1–2 次轻松跑，质量跑仍跑 |
| 强度 | RPE 3–5 或约 70–80% 该器械 HRmax | 保留 1 次「稍难」：如 3–5×4 min 骑，中间轻松 | 轻松日心率，不在椭圆上做跑的间歇配速 |
| 质量课 | 不要 | 骑的阈值短段可以；椭圆少做全力冲 | 间歇仍在跑，除非那堂会诱发痛 |
| 开门 | 次日走路不更差、该部位不锐痛 | 同左；准备回归跑时按 S2 走跑，不从骑直接上间歇跑 | 痛了立刻改回伤后表 |

热身：骑 3–5 min 轻松齿比；椭圆 3–5 min 无阻力走圈。冷热环境仍套 [热身手册](warmup-recovery-framework.md)。

## 挂在回归树上

| 阶段 | 骑 / 椭圆 |
|---|---|
| S0 | 无痛才做。优先坐骑。时间短于伤前轻松跑。 |
| S1 | 走为主；骑/椭圆可补有氧，但当天总刺激仍算一堂。 |
| S2 走跑 | 走跑那天不要再叠长骑。非走跑日可骑 30–45 min 轻松。 |
| S3 连续跑 | 骑/椭圆降为 0–1 次，避免双有氧。 |
| S4–S6 | 只替换轻松日；质量课用跑。 |

胫骨内侧锐痛、夜间骨痛：**不要**用椭圆「因为低冲击就天天拉满」。

## 给课表的短句

`伤停有氧：室外膝不适 → 室内骑 35min 能说话（约70–80%骑心率），不算休息。`  
`能跑减冲击：周二轻松跑改椭圆 40min，周四节奏仍跑。`  
`禁止：跑量不减再加 60min 阈值骑。`  
`禁止：抄 Jakob 椭圆 14×3 min，或把 Valby 的 Arc 小时数当成健身房椭圆。`

## 精英公开例子：健身房椭圆机（就是那种双手推拉的室内机）

细表：[xt-core XT11](evidence/xt-core.md)。**只写模式，不抄他们的分钟数。**

东非公路精英几乎没有「健身房椭圆堆小时」的传统。美国/欧洲伤停或补有氧更常见。Arc Trainer、ElliptiGO、Alter-G **不是**这种机器，另见 XT11 附录。

| 谁 | 公开怎么用这种椭圆机 | 大众怎么降级 |
|---|---|---|
| **Jakob Ingebrigtsen** | 跟腱炎/术后：家里小屋里就是椭圆机。公开 **14×3 min 狠**、或 45–60 min 高强度；也配水中跑。他说椭圆保有氧，回来跑会很快。公路车他不当长期方案。 | 能说话 20–40 min。不要抄 14×3，那是世界级阈值搬家。 |
| **Matthew Centrowitz** | 2012 膝术后，Salazar 在帕克城健身房：**功率车 + 泳池 + 椭圆机** + 体能。当时室外只跑约 25–40 mile。后入选奥运。 | 伤停用椭圆当其中一堂有氧，不要军训式连做再爬山。 |
| **Natasha Wodak** | 脚趾关节炎后仍周跑很多，**每周 2–3 次健身房椭圆**当双练，不把跑量堆到 200 km。 | 能跑时椭圆只替换一次轻松跑或加一次短双练。 |
| **Allie Ostrander** | 大学大量用 Arc；之后她说**健身房椭圆最像跑**，可替 1–2 次轻松跑。质量课仍跑。 | 只替轻松日。她的「10 min≈1 英里」是自用换算，不是 RCT。 |
| **Shalane Flanagan** | 伤周泳池 + **一些椭圆**；一次 40 min 觉得很长，自称不太会用。 | 说明很多精英并不靠椭圆当主食。 |
| **Suzy Favor Hamilton** | 备战交叉里会轮换：山地车、功率车、水中跑 **或椭圆**。 | 淡季选项之一，不是全马周结构。 |
| **Conner Mantz（反例）** | 髋/骶骨还痛时硬做椭圆，**仍然痛**，后来是骶骨应力骨折。 | 骨点痛：停冲击，不要用椭圆顶着练。 |

**怎么借鉴**  
伤停：先试这种椭圆是否无痛（跟腱有时比骑车更舒服，膝/骨点不一定）。能跑：最多替 1–2 次轻松跑。机器上也要微汗，不是刷手机。

**不是健身房椭圆（别混进课表）**  
Valby 的大量交叉是 **Cybex Arc**；Meb / Hasay / Seidel 是 **ElliptiGO 户外站姿车**；Rupp / Farah 公开更多是 **Alter-G / 水下跑台 / 水中跑 / 功率车**。
