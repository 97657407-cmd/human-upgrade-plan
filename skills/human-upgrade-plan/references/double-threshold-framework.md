# 双阈值 / 乳酸引导阈值间歇（挪威线）

核验日期：2026-10-28。证据：[double-threshold-core](evidence/double-threshold-core.md) DT01–DT12。  
组间秒数仍交叉 [间歇组间休息](interval-rest-framework.md)。合读知识文：[间歇·控时·双阈值](interval-training-playbook.md)。有氧功率课（4×4 / 30-30）不是本手册主菜。  
**不是医疗。** 无血乳酸仪时用 RPE/能说话短句控强，不假装测到了 mmol。

用户问「挪威训练、双阈值、一天两次阈值、乳酸控间歇、Ingebrigtsen 怎么练」时加载。  
**入门、回归、周跑不稳、上班族碎片时间：默认不给双阈值。** 先单次阈值下间歇（知识大脑）。

## 0. 这套东西到底是什么

| 名词 | 含义 | 不是 |
|---|---|---|
| **乳酸引导阈值间歇（LGTIT）** | 用间歇形式跑「阈值区」：血乳酸目标常约 **2–4.5 mmol/L**（个体差异大），配速随内部负荷调，不是死盯配速表（DT01） | 每周六次 VO₂max 狠间歇 |
| **双阈值日** | **同一天早晚各一次**阈值强度课（中间数小时恢复），用来在可恢复前提下堆更多阈值时间（DT02–DT05） | 早晚都跑到 Rec 区 / 两次 4×4 |
| **挪威精英周** | 大约 **120–180 km/周**；约 **75–80%** 低强度；周 **2–4** 次阈值（常含双阈值日）；另 **1–2** 次很短、很高的刺激；基础期少做「阈值以上的长间歇」（DT02） | 爱好者抄公里数 |

逻辑（综述口径）：阈值附近疲劳生成低于更高区，间歇形式又能用 **更高绝对速度** 多招运动单位，同时代谢仍压在阈值带 → 理论上能堆更多「有用分钟」（DT01）。急性实验：一次长 MIT 比拆成两次短 MIT 更「飘」、次日疲劳感更重；拆开可能让人累计更多该强度时间——**不等于已证明成绩更好**（DT03）。

## 1. 精英方法骨架（只借结构，不借剂量）

来自 Casado/Bakken/Tjelta 叙述 + Kelemen 系统综述 + Bakken 实践文（实践≠RCT）：

**周结构（基础期常见描述）**

1. 大量能说话轻松跑（主体积）。  
2. **2–4** 次阈值强度课：连续或间歇；常做成 **周二/周四双阈值日**（早+晚）。  
3. **约 1** 次更高刺激（短山上坡、短冲、或 z4/z5 短段）——体积远小于阈值课。  
4. 赛前：阈值课变少，比赛配速课变多（DT02）。

**单堂 LGTIT 常见形状（精英描述，DT01/DT05）**

| 时段 | 段长示例 | 强度锚 | 组间 |
|---|---|---|---|
| 双阈值·早 | 较长段：约 **6–10 min** 或 2–3 km 级 | 偏阈值下沿 / 接近马拉松感；乳酸常压得更低 | 短轻松：约 **1–2 min** 级（文献实验常用 2 min） |
| 双阈值·晚 | 较短段：约 **400–1000 m** 或 45–90 s 微间歇 | 略快、可摸到阈值附近上沿；仍用乳酸/RPE 刹住 | 很短：约 **15–90 s** 走/慢跑 |
| 单次阈值日 | 总「硬」距离常描述在约 **8–12 km** 量级（精英） | 2–4.5 mmol 目标带；每 1–3 段测一次乳酸（有仪） | 以能维持目标乳酸为准 |

Bakken 经验口径（实践文）：很多人把「实验室 4.0」当阈值会练太狠；他倾向多数课压在大约 **2.3–3.0** 一带，才能堆量大还不垮（DT05）。**个体差异大**——肯尼亚精英阈值乳酸可更低。无仪用户：**能说话短句、RPE 约 6–7（1–10）或 Borg 12–16 一带**，下一趟还能稳住；飘了就减速，不靠意志加配速。

**Talsnes 2024 实验锚（DT03）**  
- SINGLE：`6×10 min`，段间 **2 min**  
- DOUBLE：两次 `3×10 min`，两次之间 **约 6.5 h**，段间同样 2 min  
→ 用来理解「拆开 vs 一次做完」的急性差异，不是爱好者周课表。

**Casado 转述的 Ingebrigtsen/LGTIT 课形（DT10，精英）**

| 块 | 描述口径 |
|---|---|
| 较长阈值段 | 约 2000–3000 m，近半马感 |
| 较短阈值段 | 约 400–1000 m，近 5K–10K 感 |
| 单堂硬量 | 约 8–12 km 量级 |
| 重复间休息 | 约 20 s–1.5 min |
| 周结构 | 常同日两堂 LGTIT + 另 1 堂更高区短刺激 |
| 监控 | 乳酸/心率；配速随内部负荷改 |

兄弟个案另报备战约 **140–160 km/周**、约 **23–25%** 阈上（DT09）——只作背景，不抄。

## 2. 爱好者 / 上班族怎么降级（必须抄这张）

| 阶段 | 可以做什么 | 禁止 |
|---|---|---|
| 入门 / 回归 / 近 2–3 周几乎没跑 | 金样轻松底；质量最多 1 次短节奏 | 双阈值、LGTIT 周 3–4 次 |
| 有稳定轻松跑 ≥3 周，想试阈值 | **每周 1 次**单阈值：如 `3–5×6–8 min` 舒适偏难，组间慢跑 **2–3 min** | 当天第二次质量；抄 150 km 周 |
| 进阶、恢复好、想加阈值体积 | 先把单次改成 `4–6×8–10 min` 或切成两段连续；仍 **一周一个质量位** 为主 | 无监控就上周两次双阈值 |
| 「我就要挪威」 | 最多改成：**一周两个分开的阈值日**（中间隔轻松日），每堂减半体积；仍不默认同一天两次 | 早晚都上酸、用腕表当乳酸 |

小腿易紧、力量重建年（如当前主目标是增肌）：阈值间歇体积再砍一档；力量日与阈值日不要硬叠。

## 3. 研究报告方法 → 教案模板

**A. 单阈值（默认爱好者）** — 借 Casado/Bakken「间歇化阈值」  
`热身 → 3–5 × 6–8 min 能说话短句/RPE 6–7 → 组间慢跑 2–3 min → 放松`  
有仪：目标带常见叙述 2–4.5 mmol，实践常更偏 2.3–3.0 才能堆量（DT05）。

**B. 双阈值日（仅进阶）** — 借 Talsnes「拆开更好攒」+ 兄弟课形  
- 早：`3–4 × 6–8 min`，组间 2 min，偏阈值下  
- 间隔 ≥4–6 h  
- 晚：`6–10 × 400–1000 m` 或 `8–12 × 45–90 s`，组间 30–90 s，略快仍刹住  
- 两堂硬量合计先压在约 **6–10 km** 内（精英常 8–12 km/堂量级，禁止照抄）

**C. 禁止混煮**  
同周再叠 4×4 / 30-30 / 狠一千米冲 = 多个主刺激。知识大脑：本周一个质量位（双阈值日算一个硬日）。
