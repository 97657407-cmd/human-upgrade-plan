# 训练决策协议

## 1. 判断今天能承受什么

核对目标、实际负荷、症状、睡眠/精力、进食、环境和可用时间。若用户已授权 COROS MCP，先用近期活动、睡眠与恢复状态核对“实际负荷”，再与主观反馈交叉验证；无 MCP 时以自述为准。对需要新信息才能安全安排的高强度课，先补关键问题；对一般低负荷活动给条件分支。

症状性质、发展趋势和功能变化优先于单一数字（含恢复百分比、睡眠得分）。疼痛分数可记录本人趋势，但不能以“低于某分即可跑”作为通用许可。正在发生胸痛、晕厥、严重气短等情况应停止运动并寻求紧急帮助；持续心悸、局灶骨痛、进行性肿胀或步态改变需适当评估。

## 2. 明确阶段与主目标

| 状态 | 当前重点 | 进阶依据 |
|---|---|---|
| 入门或长时间中断后 | 可重复的活动习惯、技术与低剂量负荷 | 真实完成率、次日反应、动作与意愿 |
| 基础发展 | 稳定有氧/力量与逐步速度暴露 | 多次同类课耐受、恢复及相关测试 |
| 专项发展 | 项目关键速度、持续时间、比赛执行 | 阶段测试与课后恢复均支持 |
| 赛前 | 熟悉比赛要求、管理疲劳 | 比赛日期、累积疲劳与个体减量反应 |
| 赛后/高压力期 | 恢复日常功能和睡眠、渐进返回 | 症状、精神和日常功能的改善 |

阶段可回退或维持，无固定周数闸门。先选本阶段最重要的能力，再安排辅助能力；多项目并行按比赛优先级决定，不默认速度和长跑永远冲突或永远兼容。

## 3. 开出完整剂量

跑课写明热身、工作段时间/距离、强度依据、恢复方式与时长、组数、放松、环境调整。力量写动作类别、组次、余力或RPE、组间休息、技术要求及熟悉程度。不要用历史PB推配速，不把不同RPE尺度混用。

解释为什么这堂课适合当前阶段、如何与前后训练衔接。关键课优先放在精力和时间允许的位置；忙碌日提供短版、休息版。改变一个主要负荷变量通常便于追踪反应，这是实践策略，不是固定伤病预防公式。

强度依据优先近期可信测验、平时训练反应和目标课型；未知最大心率时不给看似精确的个人心率区。百分比速度若使用，说明基准是最大速度、比赛速度还是其他测试。

## 4. 执行后调整

先检查健康与功能，再判断目标刺激和动作质量，再看数据与环境，最后判断下一课维持、减量、移时或逐步增加。完全休息和取消训练均为有效决策；交叉训练仍有负荷，不能自动等同休息。

升级依据是可重复完成、次日与后续反应、阶段能力变化。不要保证“身体素质领先强度就一定无伤”。持续疲劳、表现下降要同时考虑工作、睡眠、能量、疾病等因素，不在线确诊过度训练。

## 5. 学习与证据

引用与本次决策真正相关的证据，简述研究对象和外推边界。把通用生理学、研究结果和个体教练推断分开。交付计划时按 [输出格式](output-patterns.md) 写清设计理由、原理与文献边界。涉及疾病或补剂时及时核验权威临床/运动营养来源；不把skill当医疗诊断或处方工具。

## 6. 设备数据不替代判断

手表配速、心率、训练负荷和恢复指数用于缩小未知范围，不自动决定间歇配速或是否带伤训练。厂商成绩预测与阈值仅作参考模型。向 COROS 写入计划前必须得到用户对具体内容的确认。
