# 大众跑痛闸门（骨 / 胫骨内侧 / 膝外侧 / 髌前）

核验日期：2026-10-28。证据：[runner-pain-core](evidence/runner-pain-core.md) RI01–RI12。  
**不命名疾病、不开药、不设分数许可。** 红旗停诱发并就医。阶段门走 [回归树](gold-weeks-and-return.md)。部位减冲击仍对照 [伤病负荷](injury-load-framework.md)。跟腱走等长手册。

用户说膝外侧、下坡外侧痛、胫骨内侧越跑越锐、髌前上下楼痛、夜间骨头一点按到底痛、或「医生说可以开始慢跑了怎么加」时加载。不要猜成具体病名。

---

## 0. 先分流

| 信号 | 做 |
|---|---|
| 夜间局灶骨痛、一处按到底痛、单侧小腿肿热、跛、枪响、膝锁 | **停跑**。骨应力按怀疑转介（RI01、RI02）。不走 S2 |
| 胫骨内侧酸、越跑越锐，无夜间点痛 | 砍冲击/坡/速度；走或骑（RI03） |
| 膝外侧、下坡或弯道加重 | 砍下坡速度、弯道质量、突然加量（RI04） |
| 髌前、下蹲底、上下楼、久坐后加重 | 取消深跳、下山速度、深蹲；髋+膝力量低量（RI05） |
| 跟腱晨起第一脚 | 等长手册，不走本表当 ITB |

禁止：「你这是应力骨折/髂胫束炎」；护具拉伸当治愈；痛着照旧质量。

## 1. 今天课怎么改（抄进教案）

| 像哪一类 | 今天 | 不要 |
|---|---|---|
| 骨应力红旗 | 休息或无痛上肢；就医 | 走跑试、间歇、「恢复 90% 就能跑」 |
| 胫骨内侧酸 | 走/骑或大砍平路轻松；无 * | 拉伸神操、护腿、压缩袜当处方（RI03 未证明） |
| 膝外侧 | 平路轻松若次日不更差；无下坡质量 | 大力拉髂胫束当特效；突然加弯道 |
| 髌前 | 平路能说话；力量改髋推/短行程；无跳 | 深跳、长下坡当「强化」 |

回归仍要连续 2–3 次成功且次日不更差。失败退一阶段。

```text
**痛闸**
像：骨红旗 / 胫骨内侧 / 膝外侧 / 髌前 / 跟腱（改等长手册）
今天：停质量 · 改走骑或平路轻松
取消：夜间点痛、跛、次日更差 → 停跑转介
```

钉卡：夜痛用 RI01；胫骨用 RI03；膝外侧 RI04；髌前 RI05。一次最多 1–2 张。

## 2. 骨应力怀疑：临床放行后怎么加回跑（原则）

**未放行 / 仍有夜痛点痛 / 跛** → 不排走跑表（RI01、RI06）。

**已获临床放行**（RI06–RI07）  
1. 复跑前确认：压痛大体消退、能无痛走路；高危部位按医嘱影像。  
2. 平路 **走跑间歇**，隔日；跑中/跑后/次日症状挑起 → 停并退阶。  
3. **先加总跑距，再谈连续跑日，最后才速度/坡/间歇。**  
4. 不套「每周 +10%」万能公式。  
5. 同期处理突然加量、能量不足、冲击面（交叉女选手/伤病负荷）。  
6. 旧 PB、旧 CS、体测计时 **不进** 回归前几周。

```text
**骨应力回归（需已临床放行）**
形状：走跑 · 隔日 · 先距离后速度
闸：症状挑起即退阶；禁止恢复分放行
```

---

## 3. 跟腱 / 髌前 / 膝外侧：同一套闸，形状不同

与回归树 S0–S6 并用。不跳级。不设「疼到几分还能跑」。次日更差或跛 → 退一阶段。

| 部位 | 现在允许 | 还不许 | 最后才加 | 钉 |
|---|---|---|---|---|
| 跟腱（无枪响、能走） | 等长/慢提踵（等长手册 C）；晨僵不加重后平路走跑 | 跳、上坡冲、单腿快提踵 | 速度 | RI09 |
| 髌前 | 平路能说话或走跑；髋+膝力量、无深跳 | 下山配速、深蹲底、跳 | 下坡与速度 | RI10 |
| 膝外侧 | 平路短轻松，若次日不更差 | 下坡、弯道质量、突然加量 | 速度与坡 | RI11 |
| 骨应力（已放行） | 见第 2 节 | 间歇、下山、计时 | 速度 | RI06–RI08 |

```text
**部位回归**
部位：跟腱 / 髌前 / 膝外侧 / 骨
阶段：S?
今天形状：先力量或先距离 · 无速度无坡
退阶：晨僵加重 / 上下楼更痛 / 下坡后更锐 / 夜痛
```

钉卡一次 1–2 张。四部位对照用 RI12，不必四张全贴进教案。
