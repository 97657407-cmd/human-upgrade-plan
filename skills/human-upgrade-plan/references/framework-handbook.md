## 铁律

1. **先用知识大脑做取舍，再用本手册写七天**（金样 → 项目框架 → 力量菜单 → 决策协议）。不把 50 篇或专项卡逐条塞进课表。
2. **文献只填「为什么」**：从总索引按项目/主题检索，**一次计划最多挂 1–2 张卡**。用户明确要求学习论文时，才按 INDEX-all 多读。
3. **有痛先走回归树**，未到 S5 不排质量课；无伤再套金样。
4. **场地改动作，文献不改金样骨架**。宿舍弹力带就写弹力带，不写杠铃高翻。
5. 原理、文献要点、针对该用户的推断必须分开写。

## 项目 → 手册骨架 → 优先检索标签

排课先选左列金样/菜单；解释时再用右列标签去 INDEX-all 搜卡。

| 项目 | 手册骨架 | 优先检索标签 |
|---|---|---|
| 100m / 200m / 400m | 金样 2 的速度日思路（短加速干净）+ 力量「100–400 菜单」；不排长乳酸堆 | `短跑` `弹性` `同期` `力量处方` |
| 800m / 1500m | 金样 2 + 力量「800 菜单」；[800/1500 框架卡](evidence/middle-distance-framework.md) | `中短跑` `4x4` `乳酸阈` `极化` `挪威` |
| 3000m / 5000m | 金样 1 或 4（看周次数）+ 力量「5K–半马菜单」 | `5K` `工作日` `HIIT` `弹性` `冬季打底` |
| 10000m / 半马 | 金样 4 + 力量维持；长课按时间 | `半马` `长跑剂量` `阈值` `减量` |
| 马拉松 | 金样 4 拉长有氧，不把阈值当比赛配速；补给单独练 | `马拉松` `碳水` `补给` `碳板` `LEA` |
| 越野 | 金样 4 的长课改「时间+爬升」；力量加重离心/单腿；下坡单排 | `越野` `下坡` `离心` `越野损伤` |
| 健康跑 / 上班 5K | 金样 1 / 第一周样例 A | `工作日` `久坐` `零食式运动` `睡眠` |
| 增肌主业 | 金样 3 + 力量第 8 节；有氧上限写死 | `增肌` `ACSM` `同期干扰` `超组` `冰浴悖论` |
| 伤后 / 痛 | 回归树 S0–S6 + 力量第 9 节变式 | `防伤` `膝` `跟腱` `下背` |

无明确项目时：按建档表默认金样 1，检索用 `工作日` + `睡眠`。
