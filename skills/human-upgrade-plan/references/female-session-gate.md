# 开课闸门：女选手今天这一堂（经期、头晕、漏饭）

核验日期：2026-10-12。证据：[female-endurance-2024](evidence/female-endurance-2024.md)、[iron-female-2024](evidence/iron-female-2024.md)、[session-gate-framework](session-gate-framework.md)。  
建档 `girl` 才默认走本表。`boy` 不用经期枝。未告知性别则用症状问，不猜。

**不按月经周期公式改配速。** 个体差大（female-endurance-2024）。经期可自愿说，不强迫。补铁必须医嘱，本 skill 不开铁剂。发烧仍先走生病闸门。

北京中考生理期可申请缓考（[北京体考](beijing-pe-exam.md)），那是学校手续，不是训练许可。

## 0. 今天怎么改

先问（有一项问一项，不要盘问隐私）：有没有经期不适、头晕、漏饭、比平时心慌、跑完特别虚。

| 情况 | 今天这堂课 | 不要 |
|---|---|---|
| 经期能正常上课、无头晕、无超量出血 | 按计划；可把 * 放她精力最好的时段 | 用「黄体期必须减量」一刀切 |
| 经期痉挛、腰腹坠、怕颠 | **取消 ***。走、轻松骑/椭圆、或上肢力量 | 操场间歇、越野长下坡、跳 |
| 经血明显比平时多、头晕、站起来黑一下 | 休息或散步。红旗持续 → 就医 | 补剂硬上、咖啡因顶着练 |
| 漏了一两顿、只喝了咖啡 | 先吃饭再决定。吃完 10–15 min 能说话走跑，加重就停；当天最多轻松 | 空腹质量课、再加 HIIT「消耗」 |
| 连续睡眠差 + 经期不适 | 取消 * | 用咖啡因代替睡眠 |
| 已诊断缺铁 / 医嘱补铁 | 按医嘱。训练跟症状：头晕不上 * | 自行加铁、用「女选手都贫血」吓人或忽略 |
| 相对能量不足迹象（反复受伤、月经明显紊乱、持续掉表现、吃得很少还加课） | **先加饭、砍课**，尤其砍质量 | 再加长课或减脂间歇 |

力量：女选手可与男选手**同频低量力量**（干扰证据更不清楚、力量保留往往更稳），不要默认少练腿。经期痉挛日改上肢或机器。

## 1. 和别的闸门的顺序

1. 胸痛 / 晕厥 / 大出血 / 发烧 → 急诊或生病闸，不走本表。  
2. 本表症状枝。  
3. 空气、热天饮水、病假空窗。  
4. 再写金样。

写整周时再走 [女选手周剂量](female-week-framework.md)：不按周期公式改金样；能量不足先加饭砍 *。

下次问：主课 + 热身反馈 +（若她愿意）今天身体是否仍不适。未说经期 ≠ 经期正常。
