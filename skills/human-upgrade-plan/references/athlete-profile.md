# 用户建档与目标评估

此文件定义建档方法，不保存真实人员数据。空白模板见 [profile-template](../assets/profile-template.md)。

首次对话**必须先完成建档**再排正式周计划。面向不特定公众用户，用分项问答收集信息；不要让用户自己组织长段自述。信息不够时给条件分支，不假装已知。

---

## 开场

先问：

> 我怎么叫你比较方便？（昵称/代号即可，不用真名）

之后全程用其称呼。未给称呼时用「你」。接着按块提问（一次抛出下列必问块，允许分条回），不要拆成 20 个单题刷屏。

### 第一轮：必问块

按块问，不要拆成 20 个单题刷屏：

1. **身份与日常**  
   学生 / 上班 / 自由职业 / 其他；上课或上班大概时段；久坐还是久站、有无夜班/考试周/出差。

2. **运动史**  
   以前练过什么（跑、球类、体能课、健身房、校队等）；练了多久；中断过没有、中断多久；有没有比赛或体测经历。没有就明确说零基础。

3. **当前目标**  
   健康能跑 / 完赛 / 提速（项目+大概日期）/ 增肌或力量外形 / 伤后恢复 / 先搞懂怎么练。主目标只能一个。

4. **近 2–4 周真实训练**  
   每周大概几次、跑多长或多累、有没有力量；没有就说没有。旧 PB 只作经验，不作现配速。

5. **身体限制**  
   有无疼、旧伤、医生限制；月经对训练的影响可自愿提（不强迫）。

6. **场地与器械（决定课表形态）**  
   - 跑步：操场 / 公园马路 / 跑步机 / 山路越野 / 几乎没地方  
   - 力量：学校健身房 / 商业健身房 / 宿舍哑铃弹力带 / 只体重 / 没有  
   - 单次大概能挤出多久、每周能练几天、通常几点练（早/午/晚）

7. **睡眠与压力**  
   一句话：睡得好不好、最近忙不忙。

8. **手表**  
   高驰 / 其他 / 没有。高驰且愿授权 → 先问用的是哪个 AI，再按 [设备数据](device-data.md)：**云端填 URL（方式一）**或**国内本机本地安装（方式二，默认）**。

已有回答直接沿用并标注日期。真实姓名、电话、地址、学校全称不是排课必需。

### 第二轮：定主任务 + 补缺

基础够用后：

- 用称呼确认：「○○，你这周最想先解决哪一件：本周课表 / 某场比赛或体测 / 伤后怎么恢复 / 力量怎么加 / 太累怎么取舍？」
- 对照下方「信息→计划类型」表，缺哪块只补哪块（最多再问 3 个缺口）。
- 再给可执行建议，并写为什么（见 [输出格式](output-patterns.md)）。

若用户自己先发了一大段，按同样字段整理后只补缺口，不要改成「请你按提纲自述」的开场。

## 信息 → 更可能适合的计划类型

建档后先匹配类型，再套 [金样课表与伤后回归](gold-weeks-and-return.md) 或力量模式。有痛先走回归树，不套金样 * 课。

| 听到的画像 | 优先方向 |
|---|---|
| 学生/上班，想 5K 或健康跑，有操场或路跑，时间碎 | 金样 1 / 第一周样例 A（模式 B） |
| 有田径或体测背景，目标 800/短中跑，中断后想捡回来 | 金样 2 / 样例 B；力量用 800 菜单 |
| 明确要肌肉大、有健身房或器械，有氧随便 | 金样 3 / 样例 C（模式 D）；有氧上限写死 |
| 半马或更长，已能周跑多次 | 金样 4 |
| 有伤/疼/跛 | 回归决策树 S0–S6，动作用力量第 9 节变式 |
| 只有跑步机 / 只有宿舍弹力带 / 没有力量器械 | 课表必须改成该场地能做的动作，不写杠铃高翻 |
| 考试周/出差/夜班 | 先减质量课密度，保轻松与睡眠 |

目标是「又要马又要巨巨巨腿」→ 当面讲清冲突，请用户选主目标，再排。

## 目标口径

明确主目标和次目标、期限、愿投入时间。区分健康活动、入门完赛、竞技提升、增肌力量、教练学习。  
成绩预测只在近期可信表现与恢复够时给条件范围；否则先定评估节点。历史成绩≠当前间歇配速。

## 私人数据管理

私人目录由用户指定，放在公共 skill / 待发布 Git 之外。多用户先确认当前代号。允许只在本对话使用、不落盘。详见 [维护与隐私](wiki-maintenance.md)。
