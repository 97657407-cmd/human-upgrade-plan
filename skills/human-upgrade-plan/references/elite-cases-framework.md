## 0. 硬规则（先读）

1. **只借原则，不借剂量。** 周公里、组数、配速表禁止原样贴给爱好者/体测。  
2. **案例 ≠ RCT。** 日记与教练转述有选择偏倚；成功常混童年、基因、团队、场地。  
3. **项目分家。** 短跑的完全恢复间歇 ≠ 中跑双阈值 ≠ 马拉松 15×1000。  
4. **当前阶段优先。** 入门/回归/力量重建年：最多借「轻松真轻松 + 质量少而干净」；不上双阈值、不上精英长间歇体积。  
5. **没有唯一路径。** Waitz / Kipchoge / Ingebrigtsen 三条都能出世界级（EC13）；禁止叠三条的硬部分。

## 2. 短跑：Haugen Table 2 → 爱好者落点

| 精英实践（EC01） | 爱好者 / 体测落点 |
|---|---|
| 加速 10–50 m、>98%、休 **2–7 min**、课量 100–300 m | `5–8×20–40 m`，走回 **2–3 min**（短跑手册 A）；课量砍半 |
| 最高速度飞 10–30 m、休 **4–15 min**；精英可 ~15 min | 多数体测周不上；校队才 `2–4×20 m 飞`，近完全恢复，隔 48–72 h |
| 专项耐力 80–150 m、休 **8–30 min** | 连续 2 周加速干净后才碰；体测用短段代替 |
| 速度耐力 60–80 m、90–95%（Vittori） | 校队准备期；大众用跨步 |
| Pfaff：加速 / 最高速度 / 专项分日（EC12） | 一周只留加速日为主刺激 |
| 极重雪橇（Powell 例外标注） | **禁止**当体测主课 |

钉卡：EC01、EC02、EC12；细节 SP 包。

## 3. 中跑 / 双阈值案例怎么用

**Ingebrigtsen 兄弟（备战描述，EC03）**  
- 约 140–160 km/周；约 75–80% 低强度；约 23–25% 在阈值及以上。  
- 双阈值日（周约两次）：早偏长段（叙述如 5×6 min 级）；晚偏短段（如 12×1000 / 1 min 歇，或 25×400 / 30 s 歇）；单堂阈值硬量约 8–12 km。  
- 另约 1 次更高区短刺激（如山上坡短段）+ 短冲。  
- **全程间歇用血乳酸监控。**

**爱好者降级（必须）**  
`周 1×（3–5×6–8 min，组间慢跑 2–3 min）` → 再考虑两个**分开的**阈值日 → 极少数才同日两次且体积减半。见双阈值手册第 2 节。

钉卡：EC03–EC05、DT01–DT10。

## 4. 长跑：三条路径（先选原则，再降级）

### 4.1 Kipchoge（高量少 HIT，EC06）

一般准备 ~200–220 km：Tue 长间歇（例 15×1000 / 90 s）、Thu 30–40 km、Sat fartlek；其余 Zone 1 双跑。专项期 ~185 km，质量更赛向。  
**借：** 间歇日 ≠ 长课日；专项期改形状；LIT 仍是主体。  
**禁：** 配速、15×1000、双跑公里。

### 4.2 Waitz（相对低量连续，EC11）

巅峰季 ~119–132 km：两趟/日 50–60 min 连续跑为主；长间歇很少；约每周 1 次短间歇/短冲。  
**借：** 世界级也可以「量不吓人 + 质量不堆长间歇」。  
**禁：** 把她的「相对偏快连续跑」当成爱好者轻松跑；以为「她才 120 我也能每周硬配」。

### 4.3 挪威田径 vs 马拉松日记（EC07）+ 世界级组（EC08）

准备期马组周跑常高于田径长跑；两者都大约 **~80%** 低强度连续。竞赛期田径提高专项配速份额。分区方法会改 TID 标签——别打标签战。

钉卡：EC06–EC08、EC11、EC13、IR08。

## 5. 教案里怎么引用案例（一句就够）

```text
设计说明：借 [姓名/体系] 的「___」原则（EC__），
剂量已按爱好者降级：___；不抄其周公里/组数。
```

例：  
- `借 Ingebrigtsen 线「阈值用间歇 + 内部负荷控」，本课仅 4×8 min 单阈值，组间 3 min 慢跑（EC03/DT08）。`  
- `借 Kipchoge「间歇与长课分日」，本周只有 1 次质量 + 1 次时间长课（EC06）。`  
- `借 Waitz「连续跑主体、少长间歇」，本周质量只留短跨步/短段（EC11）。`  
- `借 Haugen/Pfaff「加速够休息、分日目的」，本课 6×30 m 走回 3 min（EC01/EC12）。`
