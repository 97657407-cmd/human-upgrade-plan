# 越野赛事分析 × 检查点补给

核验日期：2026-10-22。证据：[trail-race-core](evidence/trail-race-core.md) TF01–TF05。  
训练课爬升/下坡/杖：[越野落地](trail-session-framework.md)。公路胶克数上限仍见 [赛道补给](race-fuel-framework.md)。口渴喝：[补水](hydrate-caffeine-framework.md)。磨脚：[皮肤热点](skin-hotspot-framework.md)。碳板不承诺技术路（CS05）。高原另开高原手册。  
**不是医疗、不开抗炎药、不许诺完赛。** 吐不止、意识乱、不认路、夜间骨痛 → 停。

用户报了越野/山赛/超马日期、要拆赛道或问检查点怎么吃时加载。短越野（大约 ≤3–4 h）用本文件策略格 + 降档补给；超马才抄 TF01 的 30–50 g/h。

## 0. 先问清（缺一项给分支，不编完整赛道表）

| 块 | 要问 |
|---|---|
| 手册 | 距离、累计爬升/下降、检查点间距、关门、是否夜段、强制装备（**以当年赛事手册为准**） |
| 地形 | 可跑林道 / 技术路 / 大爬 / 大下 / 泥 |
| 天气 | 起跑与山脊气温、雨、风（小时预报，北京时间） |
| 目标 | 完赛 / 关门内 / 要成绩 |
| 经验 | 是否首野；最长一次越野多久；检查点食物练过没 |
| 携带 | 软瓶/水袋容量、胶/固体、杖是否赛前用过 |

禁止：把公路半马/全马配速贴上山；禁止「全程 90 g/h」；禁止赛晨新杖、新碳板、新胶、新抗炎药。

## 1. 赛事分析（先于补给）

1. **主限制不是平路 VO2max**（TR01）：爬升经济性、下坡离心、技术路神经。课表写 **时间 + 爬升 + 路面**，不写假配速。  
2. **努力偏匀，前几爬走路合法。** 山野超马现场速度会掉到大约七成赛程，末段才可能略回（TF04）。开局配速不能外推全程。  
3. **停的时间会吃掉成绩**（TF04）：检查点补水换食物就走，不当休息厅。关门赛优先保证移动。  
4. **三档预测**仍走赛日策略：越野默认 **保守**；热、雨、技术路、没练胃、首野 → 删激进。海拔明显则加高原手册。  
5. **卡住完赛的常见是胃和脚**（TF03、TF05），不是表上的配速。

| 路段 | 策略 | 失败模式 |
|---|---|---|
| 出发–前几爬 | 锁 RPE，走不算输 | 跟公路配速党冲第一爬 |
| 可跑段 | 能说话或略快于轻松 | 用下坡把时间赚回来 |
| 大下坡 | 步频清醒；不习惯则走（TR02） | 配速表砸膝盖 |
| 夜段 | 头灯练过；减速合法 | 赛晨第一次夜跑 |
| 检查点 | 预先写：只水 / 水+胶 / 换固体；停够办事 | 每站坐 10 min |
| 末 10% | 能打开再打开（TF04） | 前半已经空，无打开可谈 |

### 1.1 怎么拆一本赛事手册（先分析，再写胶）

缺手册就给分支，不编假配速。数字以**当年赛事手册**为准，下面间距是教练落地。

1. 抄四行：**距离、累计爬升/下降、检查点表（含关门）、强制装备/夜段。**  
2. 把路线按检查点切成段。每段只写：可跑 / 大爬（走合法）/ 大下（不砸）/ 技术或泥。  
3. **预计时长**用：本人同类爬升的长课或比赛；没有 → 只给完赛/关门档，不把公路配速 × 公里。  
4. 关门：计划到达要比关门早一截（教练落地：大众至少留 **20–40 min** 缓冲，越后段越大）。缓冲吃完就只走+吃饭，不搏分段。  
5. 天气叠在山脊/夜间，不只看山脚起跑气温。下雨改鞋和减速，不改成「更快完事」。  
6. 首野、没练胃、热、雨、夜段、技术路：默认 **保守档**，删激进。

禁止发明「每 100 m 爬升加几分钟」的万能公式。有本人数据再用；没有就 RPE。

| 画像（教练落地） | 赛事分析默认 |
|---|---|
| 大约 15–35 km、爬升不大、预计 ≤3–4 h | 当「短越野」：策略抄上表，补给降到公路半马档 |
| 大约 50 km 或预计 5–10 h | 检查点当战术点；胶+少量固体；前几爬走 |
| 大约 100 km / 超马 / 夜段 | 30–50 g/h 能吃下；掉袋；胃和脚优先；停够办事就走（TF01–TF04） |

## 2. 补给分析（按预计时长，不按公路公里）

检查点往往比公路远，**胶和固体默认自己带到下一站**。赛会汤面/香蕉只吃训练吃过的。

| 预计还要多久 | 碳水怎么给 | 形态 |
|---|---|---|
| ≤2–3 h 短越野 | 同公路半马档：大约 30–45 g/h 或更少 | 胶 + 口渴喝 |
| 大约 3–8 h | 大约 **30–50 g/h**（TF01）；能吃再往上，不冲 90（TF02） | 胶 + 咸软食/赛会食物 |
| ≥8 h / 超马 | 同上，来源**多样**，后程更咸（TF01）；胃翻立刻减 | 固体比例更高；盐丸仍非默认 |
| 未练胃 / 首野 | 30 g/h 出头，优先吃得下 | 不写实验室表 |

水：**口渴抿**。不要把 TF01 的 450–750 ml/h 抄成大众强制量（低钠风险，RF10）。热天更勤抿，仍禁止体重往上喝。运动饮里的钠通常够用。

胃翻（TF03 第一退出原因）：走、只抿水、改训练吃过的咸软食，停新胶。脚热点：先贴再吃（TF05：皮肤伤会让你吃得更少）。

### 2.1 检查点之间带什么（自己带到下一站）

国内大众越野检查点常见大约 **8–15 km** 或按爬升更疏（**以手册为准**）。点上常有水、热食、香蕉，**不一定有你的胶**。

| 带到下一站 | 默认 | 不要 |
|---|---|---|
| 水 | 强制装备容量用熟；口渴抿 | 每个点灌到吐 |
| 胶 | 按该段预计小时 × 已练胃 g/h | 把公路 5 km 一袋硬套到爬坡段 |
| 固体 | ≥4–5 h 带训练吃过的咸软食 | 第一爬就吃撑 |
| 盐丸 | **不用** | 抽筋了猛吃盐再加速 |
| 头灯/杖 | 夜段/陡爬且赛前用过 | 赛晨新杖 |

掉袋（若有）：只放后程衣服、头灯、已练过的食物。不要把没练过的「赛日特供」放进去。

检查点流程（大约 1–3 min，关门赛更短）：喝/换水 → 拿已计划的食物 → 热点贴一下 → 走。坐着聊天算失败模式（TF04）。

## 3. 虚构拆道示意（禁止把真实学员赛写入公共包）

某 50 km、累计爬升约 2500 m、5 个检查点、关门 11 h、无夜段、首野要完赛：

- 档：保守。前两爬走合法。下坡不赚时间。  
- 时长：无同类数据 → 不写配速表，只写「关门内移动」。  
- 补给：未练胃大约 30 g/h；胶自己带；点上香蕉仅当训练吃过。盐丸不用。  
- 取消：第一胶就吐 → 余程只水+走；热点破皮先处理再吃。

```text
**越野赛事安排**
手册：距离 · 爬升 · 检查点间距 · 关门 · 夜段有无
档：保守/中位（默认保守）
分段：前几爬走合法 · 下坡不砸 · 检查点停够办事
补给：预计 x h → 碳水约 x g/h（已彩排 / 未练则 30 出头）
携带：出发软瓶 x ml · 胶/固体带到哪一站
水：口渴喝 · 禁止灌满
盐丸：不用（默认）
杖：无 / 仅陡爬走（已练过）
鞋：越野鞋
取消：吐了改走+抿；夜痛停；迷了等路标不硬冲
```

钉卡：策略用 TF04 或 TF03；补给用 TF01 或 TF02。不要一次钉 5 张。
