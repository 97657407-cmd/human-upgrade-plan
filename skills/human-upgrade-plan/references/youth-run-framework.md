# 青少年跑步：怎么排课（不抄成人、不混北京体考）

核验日期：2026-10-25。证据：[youth-run-core](evidence/youth-run-core.md) YR01–YR05。  
北京中考/小学统测分数：[北京体考](beijing-pe-exam.md)。等级证：[田径等级](cn-athletics-grades.md)。夜痛：[跑痛](runner-pain-framework.md)。漏饭/月经：[女选手周](female-week-framework.md)。越野超马：[越野赛事](trail-race-framework.md)——未成年默认不走超马。  
**不是儿科、不开药、不许诺成绩。** 夜痛、跛、闭经、几乎不吃饭、持续不想练 → 停诱发，转介。

触发：用户说小孩、初中生、高中生、校队、青少年、U18、想让孩子练长跑/越野。先问年龄（或学段）和目标。

---

## 0. 先问清

| 块 | 要问 |
|---|---|
| 人 | 大约几岁或几年级；boy / girl / 不答 |
| 目标 | 好玩能练 / 校运会 / 北京体考 / 路跑赛 / 越野 |
| 本周已有 | 体育课、校队、补习班、其他项目（球类/跳绳）小时 |
| 身体 | 有没有痛、夜痛、最近有没有不想练、吃饭稳不稳（女选手自愿说月经） |

禁止：按成人金样 4 的周公里排初中生；禁止「几岁必须跑半马」；禁止小学生超马；禁止用北京体考满分秒数去套国家二级。

北京体考当场仍抄体考手册。**体考以外的周跑量**走本文件。

## 1. 课表默认（教练落地）

共识写明：适跑距离证据弱（YR01）。下面是能执行的上限，不是「科学公里数」。

| 画像 | 本周怎么排 |
|---|---|
| 小学，好玩 | 玩耍 + 体育课为主。跑步用游戏、短加速、能说话慢跑。不排长课、不排间歇组。每周至少 1 天完全不跑。 |
| 初中，能练 / 校运会 | 金样骨架缩短：轻松跑为主 + **最多 1 次**很短的质量（如几趟 60–150 m 加速或轻松节奏几分钟）。力量：自重/轻器械，动作干净。 |
| 高中校队 | 仍每周 ≥1 休息日。有组织训练小时先对照年龄（YR04）。质量课每周最多 1 次。长课用时间，不抄成人半马配速。 |
| 目标是北京 800/1000 | 现场项走体考手册；平时仍要休息日，不要每天跑千。 |
| 想跑越野/超马 | 先短越野完赛。**18 岁以下默认不排 50 km+ / 超马**（YR05）。 |

**小时启发式（YR04 病例对照，不是 RCT）：**

1. 每周「校队+培训+比赛」有组织小时，先不要超过「几岁几个小时」（例：14 岁先别超过大约 14 小时）。体育课另计，但叠在一起仍要看人累不累。  
2. 有组织 : 自由玩耍不要长期 >2:1。作业把玩耍挤没了，就先砍培训课，不加班训练。  
3. 单一项目全年无休：加 1 个其他项目或真正淡季，不把「冬训」写成第二个赛季。

力量：监督下可做（YR02），低量、技术优先。不写成人 1RM 周期，不跳、不弹振当主课（除非已有基础且无痛）。

热身按大众短热身，冷天加 Raise。不写专业完整 RAMP 当默认。

钉卡：专项化/小时用 YR04；不抄成人距离用 YR01；超马用 YR05。一次 1–2 张。

## 3. 和成人课表的差别

| 成人常见 | 青少年 |
|---|---|
| 金样 4 拉长有氧 | 缩短、能说话，长课不是半马彩排 |
| 每周 1 次质量可以偏狠 | 质量更短、更稀；恢复日必须像休息 |
| 越野按爬升加时间 | 可以短越野；不加超马 |
| 备赛减量抄成人 3 周 | 校运会前少比赛、少加新课，不堆量 |
| 碳板/90 g/h | 不给未成年人开新科技和实验室胶表 |
