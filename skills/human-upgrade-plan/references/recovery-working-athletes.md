# 工作、休息与恢复

阅读相关 [恢复证据卡](evidence/recovery-work.md) 后再引用研究。以下安排是可根据个体调整的教练推断。

## 三类休息

组间休息决定下一组质量和当堂密度；课间恢复决定能否接受下一次刺激；睡眠为持续适应提供支持。恢复跑、力量“激活”和交叉训练都可能增加负荷，完全休息不需要用一堂课替代。

## 下班后怎么选择

| 当前情况 | 可选安排 | 判定依据 |
|---|---|---|
| 主要精神累，无异常症状，睡眠和进食尚可 | 自愿轻松活动5–10分钟再决定是否继续 | 活动后精神、动作和意愿；不是医学许可测试 |
| 明显困倦、全身疲劳或连续睡眠不足 | 休息、缩短或移时 | 保护睡眠机会；不靠刺激物硬撑关键课 |
| 睡眠正常、热身正常、近期耐受稳定 | 执行既定训练 | 不仅凭当天兴奋追加刺激 |
| 训练会挤压睡眠或当天进食不足 | 先安排进餐和时间调整 | 饥饿不自动等同确诊低血糖 |
| 久坐办公 | 在自然任务间隙短走、变换姿势 | 目标是减少连续久坐，不能承诺恢复或提速 |
| 久站工作 | 坐休、舒适活动与姿势交替 | 不能把办公室站立干预照搬过来 |
| 新增/加重症状、动作变形 | 取消诱发训练，按需要评估 | 不用“活动开了”作为继续硬练的理由 |

## 排班与并行训练

先询问实际排班，不假设标准双休。重要跑课、力量课根据主目标安排；同日组合时保护优先项目，缩短辅助项目。固定间隔几小时不能保证消除干扰。

午间活动可补充日常活动，但高强度“运动零食”不是疲劳者的默认方案；忙碌周减少总量不自动改成更多HIIT。漏课重排，不挤进周末。

## 监控

睡眠、精神疲劳、身体疲劳、局部反应、完成质量分别看趋势。持续不明原因疲劳、情绪或睡眠问题应适当寻求专业评估，不能仅以“休息不够”解释。

优先复用本地已核验卡。精神疲劳机制、职业压力、最低维持剂量、晚训睡眠尚需专题取证；当前6篇不能给出所有问题的确定答案。
