# 越野落地（爬升 / 下坡 / 杖）

核验日期：2026-10-22。证据：[trail-core](evidence/trail-core.md) TR01–TR05。  
补给按时间抄 [赛道补给](race-fuel-framework.md)；**越野赛日**改走 [越野赛事补给](trail-race-framework.md)。鞋不承诺碳板（CS05）。磨脚走皮肤热点。  
**不是医疗。** 跛、夜间骨痛、跟腱枪响 → 停，走伤病手册。

用户跑越野、问爬升怎么配速、下坡要不要走、要不要杖时加载。金样 4 的长课改「时间+爬升」，不要把公路配速贴上去。

---

## 0. 先问清

| 块 | 要问 |
|---|---|
| 路线 | 距离或时间、累计爬升、技术路/泥/大下坡有没有 |
| 经验 | 是否首野；最近一次类似下坡是何时 |
| 装备 | 杖、强制装备、鞋（越野鞋还是公路碳板） |
| 目标 | 完赛 / 要成绩 |

禁止：用公路半马配速开越野；下坡「把时间赚回来」；第一次比赛新杖新碳板一起上。

---

## 1. 今天怎么跑（抄进教案）

| 路段 | 做什么 | 不要 |
|---|---|---|
| 平缓可跑 | 能说话或略快于轻松，看 RPE | 抄公路配速表 |
| 上坡 | 锁努力。走合法（TR01） | 死磕配速 |
| 陡爬 | 走；有杖且练过则用杖（TR05） | 平路慢跑也插杖「省能」 |
| 下坡 | 步频清醒、视线看路；不习惯则缩短或走（TR02） | 用配速表砸膝盖 |
| 技术路/泥 | 走或慢跑，完赛优先 | 碳板收益承诺 |

**首野：** 只完赛。爬升段走路不算失败。

---

## 2. 本周结构（金样 4 的越野改法）

- 长课：按 **时间 + 爬升**，不按公路公里。  
- 质量：不要放在狠下坡的次日（TR02、TR03；习惯越野者次日仍有神经肌肉改变）。大约 **1–2 天** 只轻松或休。  
- 力量：单腿 + 离心（下台阶/慢下蹲），低量。  
- 下坡暴露：赛前用 **短、可重复** 的下坡，不要第一次就 40 min 实验室剂量。  
- 补给：按预计时长，不按公里（RF）。

```text
**越野**
路线：时间 x min · 爬升约 x m · 路面
配速：RPE/心率，不抄平路
上坡：走合法 · 杖：无 / 仅陡爬走（已练过）
下坡：清醒；不习惯则走
次日：无质量（若本堂下坡多）
鞋：越野鞋（碳板不承诺）
```

钉卡：上坡/下坡机制用 TR01；下坡恢复用 TR02 或 TR03；杖用 TR05。不要一次钉 5 张。
