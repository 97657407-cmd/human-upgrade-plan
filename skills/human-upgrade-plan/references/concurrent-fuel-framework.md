# 跑 + 力量时的蛋白与能量

核验日期：2026-10-28。证据：[concurrent-fuel-core](evidence/concurrent-fuel-core.md) CF01–CF04。  
交叉：[力量模式](strength-training-modes.md) · [同期干扰](evidence/concurrent-interference-2024.md) · [女选手周剂量](female-week-framework.md) · [赛道补给](race-fuel-framework.md)。

用户问「跑加力量要不要吃很多蛋白、3 克/公斤能不能抵消干扰、力量日要不要空腹跑」时加载。  
**不是营养处方，不开补剂，不处理肾病。**

---

## 0. 落地四句

1. **先吃够整天的饭，再谈蛋白粉。** 漏饭、相对能量不足：先加饭、砍课（女选手手册），不靠加蛋白「补上」。  
2. **健康成年人同期训练，蛋白大约每天 1.6 g/kg、分到三餐以上，是够用的起点。** 再翻倍到 3.2 g/kg **不能**当成抵消干扰的办法（CF02、CF03）。  
3. **蛋白救不了课表。** 硬跑和硬下肢力量仍要错开；同日两次硬腿，多吃蛋白并不取消力量增幅变钝（CF01、CF02）。  
4. **质量跑和力量课当天要有碳水，不把关键课放在空腹。** 轻松日可以按日常吃，不必赛日那种 90 g/h。

---

## 1. 今天怎么写进课

| 今天 | 吃 | 不写 |
|---|---|---|
| 轻松跑 | 正常饭；蛋白跟全天，不单开「跑者蛋白窗」 | 空腹打卡、氮泵 |
| *质量跑 | 课前吃过一餐含碳水的饭；课后正常饭 + 蛋白食物 | 用凝胶代替正餐；赛晨才试的新补剂 |
| 力量日 | 当天蛋白落在这餐里（肉蛋奶豆或同等食物）；硬腿课后有碳水 | 3.2 g/kg 目标；用蛋白粉替代错开硬课 |
| 增肌优先（模式 D） | 蛋白和能量都要够，跑量已经砍过 | 边高量间歇边堆到 3 g/kg 求「两边满分」 |
| 肾病、医生限制蛋白 | 不给克数 | 任何 g/kg |
