# 私人用户档案（空白模板）

复制到用户指定的私人目录后填写；公共包内此模板保持空白。

- 用户代号：
- 建档日期/最近确认日期：
- 来源与不确定项：
- 主目标、次目标与日期：
- 训练年限和中断情况：
- 最近7–28天实际训练：
- 近期可核验表现（日期、条件；历史PB另列）：
- 当前症状及运动限制（如有）：
- 医疗专业建议（如有，注明来源/日期）：
- 睡眠、进食、精神和身体疲劳：
- 工作坐站/轮班、旅行、每周可用时间：
- 可用场地器械、力量技术经验：
- 手表/设备品牌与型号（可选）：
- COROS MCP 是否已授权（是/否/不适用）：
- 可选身体信息（仅填写与目标相关项）：
- 训练与学习偏好：
- 数据保存与分享偏好：
- 下一次评估问题：

不填写真实姓名、电话、精确地址或单位名称等非必需信息。不得将填好的副本保存回公共skill。
